얼룩

얼룩 안내는 자주 묻는 얼룩 여덟 가지를 집에서 다루는 법과 맡겼을 때의 요금입니다.

커피

집에서 할 것

  1. 마른 휴지로 눌러 물기를 먼저 빼낸다.
  2. 찬물을 뒤쪽에서 부어 밀어낸다.

하지 말 것

  • 뜨거운 물을 붓지 않는다. 단백질이 든 우유 커피는 열에 굳는다.
  • 맡겼을 때 · 부분 세척 후 세탁세탁 요금에 포함

김치 국물

집에서 할 것

  1. 고춧가루를 털어 낸다.
  2. 주방 세제를 묻혀 찬물로 두드린다.

하지 말 것

  • 문지르지 않는다. 고추기름이 넓게 번진다.
  • 맡겼을 때 · 기름 얼룩 처리 후 햇빛 건조+2,000원

볼펜

집에서 할 것

  1. 밑에 마른 천을 대고 소독용 알코올을 묻혀 두드린다.

하지 말 것

  • 물을 먼저 묻히지 않는다. 잉크가 퍼진다.
  • 맡겼을 때 · 용제 부분 처리+3,000원

화장품

집에서 할 것

  1. 클렌징 오일을 조금 바르고 5분 둔 뒤 주방 세제로 헹군다.

하지 말 것

  • 파운데이션을 물티슈로 문지르지 않는다.
  • 맡겼을 때 · 용제 부분 처리+2,000원

피

집에서 할 것

  1. 바로 찬물에 담가 두드린다.

하지 말 것

  • 따뜻한 물을 쓰지 않는다. 피는 열에 굳어 빠지지 않는다.
  • 맡겼을 때 · 효소 세제 처리+2,000원

식용유

집에서 할 것

  1. 밀가루나 베이킹소다를 뿌려 기름을 빨아들인 뒤 털어 낸다.

하지 말 것

  • 물만으로 빨지 않는다.
  • 맡겼을 때 · 드라이 용제 처리+2,000원

적포도주

집에서 할 것

  1. 소금을 덮어 물기를 빨아들이게 한다.
  2. 찬물로 헹군다.

하지 말 것

  • 흰 포도주를 부어 지우려 하지 않는다. 얼룩이 넓어진다.
  • 맡겼을 때 · 산소계 표백 부분 처리+3,000원

땀(누런 얼룩)

집에서 할 것

  1. 겨드랑이·깃을 주방 세제로 문질러 30분 둔 뒤 빤다.

하지 말 것

  • 다리미로 바로 다리지 않는다. 열에 누렇게 굳는다.
  • 맡겼을 때 · 산소계 표백 부분 처리+3,000원
