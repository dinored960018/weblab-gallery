The library

A seed library run by members in Brackwater. Seed is lent, grown in local gardens and allotments, and returned.

Rules

  1. Membership is free. One card per household.
  2. Five packets per member per season.
  3. Open-pollinated varieties only. No F1 hybrids, no treated seed.
  4. Return seed, or the unused packet, by 30 November.
  5. Hard varieties are grown as pooled lots — ask first.
