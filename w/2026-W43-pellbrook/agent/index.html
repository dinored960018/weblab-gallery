Order agent

Rule-based assistant. Answers from this site’s own tables. No language model, nothing sent, no payment.

Wed 21 Oct 2026 · 10:00Rules and log

01

What it does

Does

  • Turns ticks and typed commands into ledger lines
  • Looks up specs, prices and stock from the cut list
  • Works out the next delivery from a district code
  • Finds a lot from the code on a case label
  • Totals kg, cases and cost

Does not

  • Send, confirm or pay for an order
  • Change prices or hold stock
  • Answer anything outside these tables
  • Remember the ledger after the tab is closed
