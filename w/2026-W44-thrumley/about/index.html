    Notice

    • Forms on this site check what is typed and send it nowhere; there are no payments.
    • Figures are invented within UK removal-trade ranges for 2026: hourly rates, volumes per room, box sizes.
    • Built as a design exercise: a 12-column asymmetric grid with one large number per page.
