시작하기

첫 요청까지 4단계

키를 만들고, 모델을 올리고, 배포하고, 요청을 보냅니다. 평균 94초면 배포가 끝납니다. 요청 주소는 v2 입니다(v1 은 2027년 1월 31일 닫음).

01키 발급

콘솔 「키」에서 새 키를 만듭니다. 키는 만들 때 한 번만 보입니다.

키는 환경 변수 SB_KEY 에 넣고 코드에 적지 않습니다.

02모델 올리기

모델 파일을 저장소에 올리고 비트(16 · 8 · 4)를 고릅니다.

비트별 70B 모델 메모리
비트필요 메모리들어가는 등급
16비트168GBG80×8
8비트84GBG80×8
4비트42GBG48 · G80 · G80×8

03배포

등급 · 대수 · 리전을 고르면 평균 94초 뒤 요청을 받습니다.

터미널
sb deploy law-search-prod \
  --model ./models/law-34b \
  --bits 8 --grade G48 --count 2 --region seoul
# 배정 → 모델 적재 → 상태 확인 · 평균 94초

04첫 요청

배포 주소로 요청을 보냅니다. 응답에 쓴 토큰 수가 같이 옵니다.

curl https://api.saebyeok.example/v2/deployments/law-search-prod/generate \
  -H "Authorization: Bearer $SB_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "임대차 계약 해지 통지 기간", "max_tokens": 512}'
import os, requests

r = requests.post(
    "https://api.saebyeok.example/v2/deployments/law-search-prod/generate",
    headers={"Authorization": f"Bearer {os.environ['SB_KEY']}"},
    json={"prompt": "임대차 계약 해지 통지 기간", "max_tokens": 512},
    timeout=30,
)
print(r.json()["text"], r.json()["usage"]["tokens"])
const r = await fetch(
  "https://api.saebyeok.example/v2/deployments/law-search-prod/generate",
  {
    method: "POST",
    headers: { Authorization: `Bearer ${process.env.SB_KEY}`, "Content-Type": "application/json" },
    body: JSON.stringify({ prompt: "임대차 계약 해지 통지 기간", max_tokens: 512 }),
  }
);
const { text, usage } = await r.json();

자주 묻는 질문

사업자 확인 뒤 G24 · G48 은 바로 빌릴 수 있습니다. G80 · G80×8 은 첫 배정 전에 상담을 거칩니다.

서버가 켜진 분만 셉니다. 중지한 서버는 저장소 요금만 나갑니다.

같은 달 안에서 한 번, 같은 값 이상 등급으로 바꿀 수 있습니다.
