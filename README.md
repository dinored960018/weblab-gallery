# weblab-gallery

웹 디자인 훈련 아카이브의 **공개 갤러리**입니다.

→ **https://dinored960018.github.io/weblab-gallery/**

한 주에 열 칸. 모작 다섯, 실무 다섯. 채워지는 대로 여기 쌓입니다.

## 이 레포에 있는 것

- `index.html` — 갤러리. 자동 생성됩니다. 직접 고치지 않습니다
- `w/<주차>-<종류>-<번호>-<슬러그>/` — 작업 페이지와 썸네일

작업 소스와 분석(원본 스크린샷, 해부 문서, 장단점 분석)은 비공개 레포에 있습니다.
여기에는 **완성된 페이지와 썸네일만** 발행됩니다.

## 발행 방법

비공개 작업 레포에서:

```bash
node scripts/publish.mjs          # 이 레포로 발행
node scripts/publish.mjs --reshoot # 썸네일 다시 찍기
```

## 주의

`CLONE`으로 표시된 작업은 **디자인 훈련용 모작**입니다.
원본 텍스트·이미지·로고를 쓰지 않았고, 모든 내용은 가상의 더미 데이터입니다.
각 페이지 하단에 그렇게 표기되어 있습니다.

작업 규격: https://github.com/dinored960018/weblab-protocol
