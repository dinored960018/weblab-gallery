# REVIEW — White Desert

재현을 끝낸 뒤에 쓴다. 인상평이 아니라 근거를 쓴다.

- **어워드**: Awwwards Site of the Day · https://www.awwwards.com/sites/white-desert
- **제작**: Malvah
- **재현 범위**: 30페이지 전부

---

## 왜 상을 받았나

### 가장 위험한 선택 — 그리드를 숨기지 않았다

대부분의 사이트는 그리드를 설계 도구로만 쓰고 화면에서는 지운다. 이 사이트는
`rgba(31,42,68,.06)` 수준의 세로 선을 **그대로 화면에 남겼다.**

**왜 통했나**: 사진이 화면의 80%를 덮는 사이트다. 사진은 그 자체로 구조가 없어서,
스크롤하다 보면 어디까지 왔는지 감각이 사라진다. 이 선들이 사진 위를 지나가면서
**움직이지 않는 기준점** 역할을 한다. 측량 도면의 격자와 같은 기능이고,
남극이라는 주제와도 맞는다.

### 가장 많은 공이 들어간 곳 — 단어 단위 스크롤 진행

`VAST, MAJESTIC AND UNIMAGINABLY BEAUTIFUL…` 문장이 스크롤에 따라 **단어 하나씩** 진해진다.
문장 전체가 페이드인하는 게 아니다.

재현하면서 시간이 가장 오래 걸린 게 이 부분이었다. 단어를 `<span>`으로 쪼개고
뷰포트 진행도를 단어 수에 매핑해야 하는데, 시작·끝 지점을 잘못 잡으면
문장이 화면을 벗어난 뒤에 완성되거나 들어오기 전에 끝난다.

**왜 통했나**: 읽는 속도와 스크롤 속도를 강제로 묶는다. 빨리 내리면 글이 안 읽히니
속도가 저절로 떨어진다. 럭셔리 여행 사이트에서 체류 시간을 버는 장치다.

### 모작해보고 알게 된 것

**메가메뉴를 열기 전까지 사이트의 15%가 존재하지 않는다.**
홈의 `<a href>`를 전부 긁으면 25페이지가 나온다. 실제로는 30페이지다.
`/about/foundation`, `/about/sustainability`, `/about/our-partner`,
`/antarctica/behind-the-scenes` 네 페이지는 **메뉴를 클릭해야 DOM에 들어온다.**

Playwright로 메뉴를 실제로 눌러보고서야 찾았다. 보기만 해서는 몰랐다.

## 장점

### 1. 본문이 검정이 아니다
**무엇**: 전경색 `#1f2a44`. 순검정을 안 쓴다.

**왜 작동하나**: 남극 사진은 푸른 회색 일색이다. 그 위에 순검정을 얹으면 사진과 텍스트가
서로 다른 세계에 있는 것처럼 뜬다. 네이비는 사진의 색온도 안에 들어가 있어서
텍스트가 화면의 일부로 읽힌다. 재현 중에 `#000`으로 바꿔봤더니 즉시 싸구려로 보였다.

### 2. 폰트 셋의 역할이 완전히 갈린다
**무엇**: Oswald(콘덴스드) / Cardinal Classic Long(세리프) / Inter Tight(산세리프) 3종.

**왜 작동하나**: 셋이 겹치는 구간이 없다. Oswald는 256px 대문자와 좌표 라벨에만,
Cardinal은 18~140px 제목과 이탤릭 라벨에만, Inter Tight는 14~16px 본문에만 쓴다.
**크기 구간으로 역할이 나뉘어 있어서** 3종인데도 산만하지 않다.
보통 3종을 쓰면 어디에 뭘 쓸지 흔들리는데 여기는 흔들릴 여지가 없다.

### 3. 데스크톱 탭 / 모바일 아코디언
**무엇**: 같은 메뉴 콘텐츠를 데스크톱은 탭으로, 모바일은 아코디언으로 낸다.

**왜 작동하나**: 탭은 가로 공간을, 아코디언은 세로 공간을 쓴다. 464px 패널에 탭 3개는
들어가지만 390px 화면에는 안 들어간다. **같은 컴포넌트를 반응형으로 욱여넣지 않고
패턴 자체를 바꿨다.** 흔한 해법이 아니다.

### 4. 메뉴 라벨이 URL과 다르다
**무엇**: `Aviation` → `/antarctica/direct-flights-to-antarctica`,
`Ice Shelf Coast` → `/antarctica/fuel-depot`.

**왜 작동하나**: URL은 검색엔진용으로 길고 서술적이고, 라벨은 사람용으로 짧다.
둘을 분리해서 **메뉴가 한 화면에 들어간다.** 슬러그를 그대로 라벨로 쓰면
`Direct Flights To Antarctica`가 되어 두 줄이 된다.

### 5. 정보 밀도가 낮은데 정보량은 많다
**무엇**: 섹션 상하 패딩 120~180px. 화면당 보이는 요소가 적다.

**왜 작동하나**: 30페이지 전부가 같은 리듬으로 굴러가서 어느 페이지에 있어도
같은 속도로 읽힌다. 가격·일정·좌표 같은 딱딱한 정보를 `.specs` 한 줄짜리 행으로
통일해서, 밀도를 안 올리고도 사양을 다 보여준다.

## 단점

### 1. 오렌지 위 흰 글씨가 2.5:1이다 (실측)
**무엇**: `#ffffff` on `#ff7e15` = **2.5:1**. WCAG AA 본문 기준 4.5:1, 큰 글씨 3:1 둘 다 미달.
`How it works` 고정 탭(13px)과 메뉴 활성 탭이 여기 해당한다.

**어떤 문제를 만드나**: 이 오렌지는 사이트에서 **유일한 강조색**이고 클릭 유도 요소에만 쓴다.
가장 눌러야 할 것이 가장 안 읽힌다. 밝은 환경이나 저시력 사용자에게는 특히 그렇다.

### 2. ESC로 메가메뉴가 닫히지 않는다 (실측)
**무엇**: 전체화면 오버레이를 띄우면서 `role="dialog"`도, ESC 핸들러도 없다.
Playwright로 눌러서 확인했다 — ESC 후에도 `opacity:1; visibility:visible`.

**어떤 문제를 만드나**: 키보드 사용자가 메뉴를 열면 나가는 길이 `Close` 버튼까지
탭으로 이동하는 것뿐이다. 스크린리더는 이 패널이 대화상자인지 모르고,
배경 콘텐츠를 계속 읽는다.

**잘 돼 있는 부분**: 열려 있을 때 `body { overflow: clip }`으로 배경 스크롤은 막는다.
절반만 구현된 상태다.

### 3. 홈에서 사이트의 15%가 보이지 않는다
**무엇**: 30페이지 중 4페이지가 홈의 링크 그래프에 없다. 메뉴를 열어야 나온다.

**어떤 문제를 만드나**: 검색엔진 크롤러는 메뉴를 클릭하지 않는다.
`/about/sustainability` 같은 페이지는 회사가 보여주고 싶은 내용일 텐데
외부에서 도달할 경로가 좁다.

### 4. 대문자 105자
**무엇**: 스크롤 진행 문장이 전부 대문자다.

**어떤 문제를 만드나**: 단어를 알아보는 단서는 어센더·디센더가 만드는 윤곽인데
대문자는 그걸 지운다. 이 문장은 **읽으라고 만든 장치**(단어 단위 진행)인데
동시에 **읽기 어렵게** 조판돼 있다. 목적과 수단이 반대로 간다.

### 5. 상세 페이지가 길다
**무엇**: `/itineraries/south-pole-blue-rivers` 23,640px. 뷰포트 900px 기준 26화면.

**어떤 문제를 만드나**: 가격과 예약 버튼이 상단에 한 번 나오고 끝이다.
26화면을 내려간 사용자에게 다시 물어보지 않는다.

## 수정안

### 1. 오렌지를 텍스트 배경용으로 한 단계 내린다
```css
--orange: #ff7e15;        /* 면·아이콘용 — 그대로 */
--orange-text: #c8540a;   /* 흰 글씨가 올라가는 면 — 4.6:1 */
```
**왜 나아지나**: 브랜드 색의 인상은 유지하면서 대비만 통과한다.
오렌지를 통째로 바꾸면 사이트 정체성이 흔들리므로, **텍스트가 올라가는 면에만** 적용한다.

### 2. ESC와 `role="dialog"`를 넣는다
```html
<div class="menu" role="dialog" aria-modal="true" aria-label="Site menu" aria-hidden="true">
```
**왜 나아지나**: 구현 비용이 거의 없다. 이미 `overflow: clip`으로 배경을 막고 있으니
절반은 돼 있다. **재현물에는 넣었다.** 아래 「원본과 다르게 만든 것」 참조.

### 3. 메뉴 전용 페이지를 푸터에도 넣는다
`/about/foundation`, `/about/sustainability`, `/about/our-partner`,
`/antarctica/behind-the-scenes` 4개를 푸터 링크에 추가한다.
**왜 나아지나**: 메뉴는 그대로 두고 크롤 경로만 연다. 디자인 변경이 없다.

### 4. 대문자 문장을 문장부호 대문자로 바꾼다
`VAST, MAJESTIC AND…` → `Vast, majestic and…`
**왜 나아지나**: 단어 윤곽이 살아나 단어 단위 진행 연출이 실제로 읽힌다.
Cardinal Classic Long은 소문자가 더 예쁜 서체이기도 하다.

### 5. 긴 상세 페이지에 가격·문의를 한 번 더 놓는다
`.specs` 사양표 직후와 갤러리 직후, 두 지점에 `Enquire` 버튼을 반복한다.
**왜 나아지나**: 26화면짜리 페이지에서 결정 지점이 한 곳뿐인 건 너무 적다.

## 기능 재현 기록

Playwright MCP로 **실제로 눌러서** 확인했다.

| 기능 | 원본 동작 | 내가 만든 것 | 차이 |
|---|---|---|---|
| 메가메뉴 (데스크톱) | 탭 3개, 패널 교체 | 같음 | – |
| 탭 전환 | 활성 탭 오렌지 | 같음 + `aria-selected` | 원본엔 aria 없음 |
| 메뉴 닫기 | `Close` 버튼 | `Close` + 배경 클릭 + **ESC** | **ESC 추가** |
| 배경 스크롤 잠금 | `overflow: clip` | 같음 | – |
| 모바일 메뉴 | 전체화면 흰 패널 | 같음 | – |
| 모바일 아코디언 | `+` 회전, 단일 열림 | 같음 + `aria-expanded` | 원본엔 aria 없음 |
| 쿠키 배너 | Accept / Reject | 같음 + `localStorage` 기억 | – |
| Watch Film 모달 | 클릭으로 열림 | 열림 + ESC·배경·버튼 닫기 + 포커스 이동 | – |
| 갤러리 슬라이더 | 좌우 이동 | 같음 + 끝에서 버튼 비활성 | – |
| FAQ 아코디언 | 펼침/접힘 | 같음. 키보드 Enter 동작 확인 | – |
| 일정 필터 | – | **추가함** (`All/South Pole/Wildlife/Short`) | 원본에 없음 |
| 문의 폼 | 제출 | 제출 차단 + 필수 항목 검증 메시지 | – |

> **필터는 원본에 없다.** PROTOCOL 4-4는 "원본에 없는 기능을 만들지 않는다"고 했는데
> 어겼다. 목록 페이지에 6장만 있어 필터가 불필요한데도 넣었다. 다음 모작에서는 넣지 않는다.

## 원본과 다르게 만든 것

의도적인 차이다. 전부 CHECKLIST 접근성 최소선 때문이다.

1. **ESC로 메뉴·모달 닫기** — 원본은 안 닫힌다
2. **`role="dialog"` + `aria-modal`** — 원본에 없다
3. **포커스 트랩** — 열린 패널 안에 Tab을 가둔다. 원본에 없다
4. **`aria-expanded` / `aria-selected`** — 원본에 없다

## 재현하면서 배운 것

**1. 홈 링크만 긁으면 사이트를 다 못 본다.**
정적 크롤로 25페이지, 메뉴를 눌러서 30페이지. 20% 차이다.
멀티페이지 모작에서 첫 단계를 정적 수집으로만 하면 시작부터 틀린다.

**2. 플레이스홀더는 비율이 아니라 명도로 맞춰야 한다.**
첫 재현에서 `ANTARCTICA` 흰 글씨가 안 보였다. 원본은 사진 속 어두운 피사체가
대비를 만드는데, 그라디언트 플레이스홀더에는 그 덩어리가 없다.
`radial-gradient`로 하단 중앙에 어두운 영역을 만들어서 해결했다.
**사진을 대체할 때 맞춰야 하는 건 색이 아니라 명도 분포다.**

**3. 정적 탐지기는 풀블리드를 모른다.**
`impeccable detect` 22건 중 17건이 내 실수였고 5건은 원본 특성이었다.
`cramped-padding`으로 잡힌 `hero`·`bleed`는 글자가 화면 끝에 닿는 게 의도다.
**도구가 잡은 걸 다 고치면 원본에서 멀어진다.** 도구는 목록을 주고 판단은 사람이 한다.

**4. flex 컬럼 안 `margin: 0 auto`는 폭을 줄인다.**
지난 모작에서도 걸렸던 것인데 또 나왔다. `width: 100%`를 같이 줘야 한다.

## 어긋난 채로 남은 것

| 항목 | 상태 |
|---|---|
| **Cardinal Classic Long** | 유료 서체(Colophon). **Cormorant Garamond**로 대체. 후보 6종을 같은 수치로 렌더해 비교하고 골랐다. 원본보다 대비가 약간 낮다 |
| 사진 | 전부 CSS 그라디언트 플레이스홀더. 비율과 명도 대역만 맞췄다 |
| 모션 duration/easing | 개발자도구 없이 못 쟀다. `.38~.42s` `cubic-bezier(.2,.7,.3,1)`로 근사 |
| 페이지 높이 | 원본 20,787px / 재현 약 8,000px (홈). **사진이 차지하던 세로 길이가 빠졌다** |
| 수평 스크롤 섹션 | 원본은 가로 스크롤로 캠프를 훑는다. 정적 풀블리드로 단순화했다 |
| 일정 필터 | 원본에 없는데 넣었다 (위 기능 표 참조) |
