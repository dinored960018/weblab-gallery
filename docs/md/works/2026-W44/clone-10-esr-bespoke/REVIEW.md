## 4. 장점

1. **두 서체 역할이 정확히 갈린다.** 큰 글(62 · 92 · 40px)은 그로테스크 500, 나머지 정보(메뉴 · 라벨 · 주소 · 번호)는 전부 14px 각진 대문자 하나로 묶었다. 크기 단계가 14 · 18 · 20 · 40 · 62 · 92 여섯 개뿐이라 페이지가 7개인데도 한 벌로 읽힌다. 라벨 서체가 자동차 계기판·차대번호 각인 같은 각진 꼴이라 업종 설명 없이 업종이 보인다.
2. **흑백 두 색만으로 구간을 나눈다.** 섹션 사이 장식 없이 흰 면 → 100svh 사진 → 흰 면 → 검정 면이 번갈아 와서 스크롤 위치를 색으로 안다. 어워드 팔레트가 `#000` `#fff` 두 개인 이유다. 사진이 실제 공장·차 사진이라 이 절제가 "고급 정비"라는 내용과 맞는다.
3. **마크 목록이 스크롤로 하나씩 켜진다.** 92px 이름 12개 중 하나만 검고 나머지는 흐리며, 화면 가운데를 지나는 이름이 켜지고 오른쪽 216px 사진이 바뀐다. 휠 한 번(약 88px)이 한 이름이라 "우리가 다루는 브랜드 목록"이라는 지루한 정보가 스크롤 장치가 된다. 심사 하이라이트 "ESR Brands" 가 이것이다.
4. **꼬리말이 첫 화면이자 마지막 화면이다.** 인트로에서 검은 화면에 로고가 올라오고 본문이 그 위로 덮여 올라간다. 끝까지 내리면 본문이 걷히고 같은 고정 뒤판(로고 · 연락처)이 다시 드러난다. 태그 "Footer Design" 의 근거. 연락처가 페이지마다 끝에서 반드시 한 화면 전체로 보인다.
5. **사진 넘김의 커서 미리보기.** 다음 사진이 커서 옆 216px 로 미리 보이고, 누르면 그 사각형이 화면 가득 커진다. 무엇이 나올지 알고 누르므로 "다음" 버튼보다 덜 막연하다.

## 5. 단점

1. **꺼진 글자 대비 1.2:1.** 마크 · 메뉴 hover 의 opacity .1 은 흰 바탕에서 `#e6e6e6` 이다. 92px 라도 WCAG 큰 글자 기준 3:1 에 한참 못 미친다. 마크 12개 중 11개를 저시력 사용자는 못 읽는다. 원본 Accessibility 점수가 6.40 으로 가장 낮은 항목이다.
2. **고정 꼬리말이 잘린다.** 꼬리말 안쪽이 `position:fixed; inset:0` 이고 아래 줄이 `1fr` 이라, 뷰포트 높이 900 에서 원본 세 번째 연락처(ESR Bespoke Studio)의 주소가 화면 밑에서 잘린다(`refs/home/vp/vp-07.jpg` "ALEXAND"). 고정이라 스크롤로도 볼 수 없다.
3. **본문 행간이 좁다.** 20px/24px(1.2), 라벨 여러 줄 14px/14px(1.0). 지점 소개처럼 7–9줄 문단은 줄을 따라가다 놓친다. 큰 문단 40px/40px 도 7–8줄이다.
4. **아코디언 · 정보 상태가 보조기술에 안 보인다.** 원본 아코디언 버튼에 `aria-expanded` 가 없고, 메뉴 링크 hover 사진·팀 hover 사진은 마우스로만 바뀐다. 이메일 검증은 브라우저 기본 말풍선뿐이다.
5. **인트로가 매번 3.6초.** 첫 화면에서 글이 한 글자씩 켜지고 본문이 올라오기까지 3.6초 동안 아무 것도 누를 수 없다. 반복 방문자에게는 대기다.
6. **h1 을 섹션마다 쓴다.** services 4개 · about 3개. 문서 구조가 평평해져 화면 읽기 프로그램의 제목 탐색이 의미를 잃는다(Semantics 7.40).

## 6. 수정안

1. 꺼진 이름 opacity .1 → **.44**(약 3.1:1). 모작에 적용했다. 더 원본 느낌을 살리려면 .44 + `font-weight 400` 으로 무게 차를 같이 주는 방법도 있다.
2. 꼬리말 아래 줄을 `1fr` 대신 `auto` 로 두고 연락처 묶음 간격 32 → 24, 라벨 아래 14 → 8. 높이 약 274 → 230 이 되어 900 화면 안에 들어간다. 또는 높이가 모자라면 `position:sticky; bottom:0` 으로 바꿔 스크롤로 닿게 한다.
3. 20px 본문 행간 1.2 → **1.3**(모작 적용), 14px 여러 줄 라벨 1.0 → 1.3(모작 적용). 40px 큰 문단은 1.0 → 1.1, 최대폭 1376 → 60ch(약 1080px)로 줄 수를 줄인다.
4. 아코디언에 `aria-expanded` · `aria-controls`, 팀 행에 `tabindex=0` + focus 로 사진, 이메일은 문구로 검증(전부 모작 적용).
5. 인트로는 세션 첫 방문만(모작 적용: `sessionStorage`), `prefers-reduced-motion` 에서는 없앤다.
6. 페이지 제목만 h1, 섹션 제목은 h2(모작 적용, 보기 크기는 62px 그대로).

## 7. 왜 상을 받았나

- **Design 7.51 이 가장 높다.** 흑백 두 색 · 서체 두 개 · 크기 여섯 단계로 7페이지를 끝까지 같은 문법으로 묶었다. 심사가 본 것은 "고급 정비소"라는 평범한 업종을 패션 브랜드 수준의 절제로 보여줬다는 점일 것이다. 태그 Luxury · Clean · Big Background Images 가 그 판단이다.
- **하이라이트 세 개가 전부 정보 구조 장치다.** Home(영상 + 큰 문장), Brands(스크롤로 켜지는 마크 목록), Navigation(큰 링크 + hover 사진 덮개). 장식 효과가 아니라 업체가 말해야 하는 것(무엇을 고치나, 어떤 브랜드 인증이 있나, 어디 있나)을 각각 한 장치에 실었다.
- **WebGL 없이 움직임을 만들었다.** 캔버스 2D 와 transform 만으로 글자 타자, 커서 미리보기, 꼬리말 걷힘을 만들어 Responsive 7.80 · WPO 7.40 을 받았다. 반대로 Accessibility 6.40 이 가장 낮은데, 위 단점 1·2·4 와 맞는다.
- Creativity 7.24 는 상대적으로 낮다. Nightjar 의 다른 작업(Odyssée — W42 모작)과 같은 손버릇(꺼진 항목 opacity .1, 아코디언 hover 흐림, 커서를 따라다니는 `z-cursor` 라벨, Sanity 사진 칸)이 보여, 새 장치보다 다듬은 완성도로 평가받았다고 본다(W42 SPEC 137 · 168행과 비교).
