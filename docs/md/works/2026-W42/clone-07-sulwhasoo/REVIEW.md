## 장점

- **정보 위계가 제품 단위로 단순하다.** 홈은 KV → 추천 → 베스트 → 시즌 → 매장 다섯 덩어리, 각 덩어리 제목 28px 하나. 섹션 사이를 120px 로 고정해 리듬이 일정하다(507 → 627 → 1437 …).
- **카드 회색(#eee) 하나로 제품 사진 바탕을 통일.** 누끼 사진이 어떤 색이든 같은 판 위에 놓여 목록이 정돈돼 보인다. 4열 393px 카드에 이름 · 영문 · 가격 · 용량이 같은 자리에 온다.
- **브랜드 페이지와 판매 페이지의 톤을 나눴다.** 카테고리 · 상세는 회색 판과 고정폭 정보, 브랜드 스토리 · 문화전 · 살롱은 큰 사진과 어두운 구역 · 가로 연혁 같은 편집 디자인. 같은 헤더 아래서 두 성격을 오간다.
- **투명 헤더 → 호버 시 흰 헤더.** KV 사진을 위까지 쓰면서 메뉴를 열면 흰 바탕으로 바뀌어 하위 메뉴 가독성을 지킨다.

## 단점 (근거)

- **대비 부족:** 보조 글자 #888 이 흰 바탕 3.5:1, 카테고리 탭 #888 on #fbfbfa 3.4:1 — WCAG AA 미달. 모작은 #6b6b6b 로 올렸다.
- **헤더가 고정되지 않는다.** 긴 페이지(라인 소개 10,452px · 제품 상세 19,380px)에서 메뉴로 돌아가려면 맨 위까지 올라가야 한다. 맨 위로 단추가 유일한 길.
- **글자 크기가 3~4가지 단위로 흩어진다.** 16.5 · 13.5 · 41.25 · 42.4 · 22.51 같은 비정수 크기가 페이지마다 섞인다(measure.json). 페이지별로 따로 만든 흔적이고 타입 스케일이 없다.
- **제품상세가 이미지 텍스트.** 약 15,000px 의 광고 이미지에 글자가 박혀 있어 검색 · 번역 · 화면 낭독이 안 된다.
- **매장찾기가 지도 스크립트에 의존.** 캡처 시 지도가 안 떠서 검색창만 있는 빈 화면이 됐다. 목록 대체가 없다.

1. 보조 글자 #888 → #6b6b6b(4.6:1 이상), 탭 비활성도 같은 값.
2. 헤더: 스크롤 내릴 때 숨고 올릴 때 나타나는 56px 축소 헤더를 둔다(전환 300ms ease-out).
3. 타입 스케일을 13 · 15 · 18 · 24 · 32 · 40 여섯 단계로 묶는다.
4. 제품상세 이미지의 문구를 HTML 글자로 빼고 이미지는 사진만 남긴다.
5. 매장찾기: 지도 실패 시에도 매장 목록(이름 · 주소 · 전화 · 영업시간)을 먼저 그린다 — 모작이 이 방식.

## 왜 골랐나 (어워드 없음)

어워드 수상작이 아니다(SPEC 「대상 선정 근거」: Awwwards 한국 목록 1~5쪽 · CSSDA · iF · Red Dot 에서 조건에 맞는 한국어 수상작 없음). 대신 국내 상업 사이트 중 한국어 화면 · 페이지 종류 20종 이상 · 3D 없음 조건을 가장 잘 채운다. 배운 점: 판매 목록과 브랜드 편집 페이지를 한 헤더 · 한 꼬리로 묶는 체계, 회색 판 카드, 투명 → 흰 헤더 전환.

## 남은 차이와 이유

- 영상 6곳을 사진으로 대신했다(원본 영상 사용 금지, 스톡 영상 도구 없음).
- 원본 로고 · 화살표는 이미지라 색 전환이 `background-image`/`filter` 로 기록된다. 모작은 글자 · SVG 라 `color` 로 같은 시간에 바뀐다.
- 목록 개수: 제품 33 · 뉴스 12 · 살롱 회차 6 (원본보다 적음, 종류는 같음). 그래서 일부 하위 카테고리 높이가 원본보다 낮다.
- 외부로 나가는 링크(구매하기 · 회사소개 · 약관 · SNS · 해외 사이트)는 내부 페이지로 바꾸거나 뺐다(SPEC 「원본과 다르게 둔 곳」).
- 사진은 Pinterest 출처 · 라이선스 미확인(규격 기본값). 상표 · 글자 · 워터마크가 보이는 52장은 지웠다. 요청이 오면 스톡으로 바꾼다.
- 하위 페이지 등장 모션(AOS)은 원본 녹화가 홈만이라 지속시간을 실측하지 못했다(800ms ease, 40px).
