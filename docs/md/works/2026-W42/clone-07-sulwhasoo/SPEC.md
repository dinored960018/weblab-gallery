**조건**: 한글 30% 이상 · 내부 링크로 이어지는 화면 5종 이상 · 3D/WebGL/렌더 영상 주도 아님 · 일러스트·캐릭터 주도 아님 · `## 제외` 와 `works/` 전부와 겹치지 않음.

## 섹션 순서

- 홈: KV(4장) → 은결담 추천(캐러셀 9) → 베스트 셀러 배너 → 시즌 추천(카드 · 큰 사진 · 카드) → 플래그십 배너 → 꼬리
- 라인 소개: KV → 인트로(그라디언트 + 사진) → 숫자 3개 → 제품 CTA(사진 · 용량별 가격 · 단추 2) → 스토리(글 + 사진 2) → 성분 2 → 기술 → 8주 결과 5 → 영상 자리 → 헤리티지
- 브랜드 스토리: 점 내비 · 필름 2장 → 원칙 → 인삼 연구 → 오미결단® → 피부 힘 → OUR JOURNEY(가로)
- 지속가능성: 제목 · 소개 · 제품 사진 · 기둥 3 · 보고서 띠 → 인삼과학 → 영상 자리 → 환경(+수치 2) → 문화
- 제품 상세: 갤러리 · 정보 → 고정 탭 → 제품상세 이미지 묶음 → 리뷰 → 함께 쓰면 좋은 제품 → 유의 사항 → 하단 고정 막대
