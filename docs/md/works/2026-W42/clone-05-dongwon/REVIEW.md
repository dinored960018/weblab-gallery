## 5. 장점

- **글자 크기 차이로 위계를 만든다.** 섹션 제목 120px 과 본문 21px 사이가 5.7배다. 장식 없이 크기만으로 어디서 섹션이 바뀌는지 보인다.
- **흰 바탕 · 어두운 바탕 교대.** 홈은 영상(어두움) → 여정(흰) → 지속가능(#11141a) → 사업(흰)으로 바뀐다. 헤더도 이 구간을 따라 투명·흰 글씨 ↔ 흰 바탕으로 바뀌어 스크롤 위치를 알려 준다.
- **사업 행의 칩이 바로 하위 페이지로 간다.** 부문 사진 위 칩 13개가 계열사 상세 링크라서 메뉴를 거치지 않고 두 번 클릭 안에 계열사 정보에 닿는다.
- **하위 페이지 머리 틀이 하나다.** 왼쪽 큰 제목 + 오른쪽 309px 칸(궤도 그림 + 사진)이 경영철학 · 사업 · 인재상 · 정도경영에 똑같이 쓰여 어느 페이지든 같은 자리에서 제목을 찾는다.

## 6. 단점

- **흐린 글자 대비가 낮다.** #b5b5b5(비활성 탭·날짜)는 흰 바탕에서 2.1:1, #939393 은 3.1:1 로 본문 기준 4.5:1 에 못 미친다. 모작에서는 #767676 · #6f6f6f 로 올렸다.
- **0.5em 자간 설명문은 읽기 느리다.** 25.5px 굵은 글자를 글자마다 띄워 한 줄에 20자 정도만 들어간다. 단어 경계가 흐려져 문장으로 읽히지 않는다.
- **프리로더가 3.5초 넘게 첫 화면을 막는다.** 원본은 2.6초 동안 빈 남색 화면을 보여 준 뒤에야 구멍이 열린다. 재방문에도 같다.
- **헤더가 내리면 사라지고 메가 메뉴는 600px 높이를 쓴다.** 900px 화면의 2/3 를 덮는다.
- **영상 속 문구.** 키 비주얼 문구("더 높이" 등)가 영상에 박혀 있어 화면 읽기 프로그램이 읽지 못한다.

## 7. 수정안

- 흐린 글자: #767676 이상(4.5:1). 비활성 탭은 색 대신 굵기 500 → 400 으로 구분.
- 넓은 자간 설명: 0.5em → 0.08em, 줄 길이 30자 안팎. 큰 제목 위 작은 제목만 넓은 자간을 남긴다.
- 프리로더: 첫 방문 1회, 전체 1.2초 이하(구멍 열림 400ms + 확대 800ms). 세션 저장소로 재방문 생략.
- 메가 메뉴: 높이를 내용에 맞춰 380px 안팎, 사업분야 칸만 펼침.
- 키 비주얼 문구: HTML 글자로 올리고 영상은 배경만.

## 8. 왜 상을 받았나

이 원본은 수상작이 아니다(3순위, 사용자 승인 범위). Awwwards South Korea 목록에 카드는 있으나 수상 라벨이 없다. 대신 심사 기준으로 본다면 점수를 받을 지점은 둘이다. 하나는 프리로더 구멍이 화면 크기로 커지며 영상이 드러나는 첫 장면(디자인·창의성), 다른 하나는 사업 · 미디어 · ESG 를 같은 크기 체계와 같은 머리 틀로 묶은 일관성(콘텐츠·사용성)이다. 반대로 대비 부족과 긴 프리로더는 사용성 점수에서 깎일 지점이다.

## 9. 남은 차이

- 영상 → 사진(키 비주얼 · CF), 3D 블롭 → 사진, 아이소메트릭 그림 → 도식, 정밀 세계 지도 → 근사 점 지도

- 원본 브레이크포인트 정확한 값은 확인하지 못했다(390 에서 버거 메뉴인 것만 확인). 모작은 1024 에서 버거로 바꾼다
