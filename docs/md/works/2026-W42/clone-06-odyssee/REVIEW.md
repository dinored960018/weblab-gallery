## 3. 모션 비교 — `refs/motion-compare.html`

- 녹화: 원본 `refs/motion-origin`(로드 5s + 스크롤), 모작 `refs/motion-mine`(같은 조건).
- **빨간 줄(원본에만 있는 모션) 0.**
- 같은 서명: `opacity 500ms cubic-bezier(0,0,0.2,1)`(사진 나타남, 원본 8 · 모작 19 — 모작은 사진이 `img` 로 더 많다), `opacity 300ms cubic-bezier(0.16,1,0.3,1)`(WHY 전환, 8 · 8).
- 파란 줄(모작에만): `opacity/translate 600ms cubic-bezier(0.16,1,0.3,1)`(블록 등장) · `opacity 1000ms`(프리로더). 원본은 이 둘을 JS 인라인 스타일로 움직인다(비교표 아래 "원본 JS 인라인" 표의 `translate(0px,10px) op 0 → translate(0,0) op 1`). 같은 값을 CSS 전환으로 옮긴 것이라 서명만 다르다.
- 1차 비교에서 고친 것: 머리막대 글자색 300ms 전환이 모작에만 있었다(원본은 즉시 바뀜) → 전환을 지우고 다시 녹화.
- 로드 순서 대조: 원본 1553ms 막 · 2360ms 반투명 · 3208ms 선명, 모작 1952ms 반투명 · 2786ms 메뉴 나타나는 중 — 같은 흐름.
- 맞추지 못한 것: 단어 스크럽의 진행 곡선. 원본 정지 캡처는 같은 화면 위치에서도 문장마다 진행 정도가 달라(소개 문장은 위치 240 에서 4/22 단어, 마무리 문장은 567 에서 9/18) 하나의 식으로 맞지 않았다. 둘 사이 값으로 `(0.85vh − top) / (0.65vh + 높이)` 를 썼다. WHY 자동 넘김 주기도 실측하지 못해 6s 로 뒀다.

## 5. 장점 — 왜 이 화면이 작동하나

1. **남색 한 색 + 크림 바탕 + 사진만으로 위계를 만든다.** 색은 `#1e305e` 하나, 크기는 12 · 14 · 18 · 32 · 48 다섯 단계뿐이다. 장식 요소가 없어서 사진의 피부 톤이 화면에서 유일한 색 정보가 되고, 미용의학이라는 업종 성격과 맞는다.
2. **불투명도로 순서를 보여 준다.** WHY 의 0.1/1, 아코디언의 0.3/1, 영업시간의 오늘/나머지, 문장의 단어별 밝아짐 — 같은 장치 하나로 "지금 볼 것"을 반복해서 가리킨다. 사용자가 규칙을 한 번 배우면 화면 전체에 통한다.
3. **고정(sticky) 레이어를 겹쳐 페이지가 짧게 느껴진다.** 홈 가운데 띠, 하위 히어로 제목, 아코디언 목록이 고정된 채 사진만 흘러간다. 10706px 시술 화면이 실제로는 "목록 하나 + 사진 다섯 장"으로 읽힌다.
4. **12칸 그리드를 끝까지 지킨다.** 들여쓰기 시작점(넷째 칸 · 둘째 칸 · 일곱째 칸)이 그리드 선에 맞아, 왼쪽 정렬이 들쭉날쭉한데도 질서가 보인다.

## 6. 단점 — 근거

1. **대비.** 비활성 글자 0.1(1.2:1), 영업시간 0.35(2.0:1), 꼬리말 링크 0.45(2.5:1), 흐린 글자 0.5(3.8:1), 프리로더 흰 글자 2.6:1. 모작에서 전부 4.5:1 이상으로 올려야 했다. 비활성 탭 제목은 읽을 수 있어야 누를지 판단할 수 있다.
2. **스크롤 연동 문장.** 단어가 0 에서 시작해, 화면에 들어와도 다 읽히기 전에 스크롤을 더 내려야 한다. 빠르게 훑는 사용자는 문장 끝을 못 본다.
3. **자동 넘김 WHY.** 멈춤 단추가 없다(WCAG 2.2.2). 원본은 호버로만 멈춘다.
4. **외부 예약 의존.** 모든 BOOK CONSULTATION 이 외부 CRM 으로 나간다. 화면 안에 가격 · 소요 시간 같은 판단 재료가 없어 예약 전 정보가 부족하다.
5. **무게.** 영상 8개 + 스크립트 23개(분석 · 픽셀 포함). 첫 화면이 프리로더로 1.5s 이상 가려진다.

## 7. 수정안 (수치)

- 비활성 글자 불투명도 최저 0.7(≈5.2:1). 사진만 0.1 로 흐려 인상을 남긴다 — 모작에 적용한 방식.
- 단어 스크럽 시작을 요소 상단이 뷰포트 85% 지점, 끝을 40% 지점으로 당겨 화면 중앙에 오면 문장이 다 보이게.
- WHY 진행 막대 옆에 일시정지 단추(12px 라벨 `Pause`) 추가, `prefers-reduced-motion` 에서 자동 넘김 끔(모작은 끔).
- 시술 항목마다 `소요 30–60 min · 회복 0–2 days` 같은 한 줄 사실 정보.
- 프리로더 최대 800ms, 히어로 영상 `poster` 로 첫 프레임 즉시 표시.

## 8. 왜 상을 받았나

- **업종과 형식의 일치.** "과장 없는 의료"라는 메시지를 장식 없는 타이포 · 단색 · 느린 전환으로 그대로 보여 준다. 미용 시술 사이트에 흔한 전후 비교 사진 · 할인 배너가 하나도 없다.
- **촬영 소재의 질.** 같은 조명 · 같은 회백색 배경의 자체 촬영 영상으로 전 화면이 이어진다. 스톡으로 대체한 모작이 가장 크게 원본과 멀어지는 지점이 바로 여기다.
- **개발 완성도(Dev Award 7.36).** 스크롤 고정 · 흐림 · 단어 스크럽 · 메뉴 미리보기 · 대기 화면 · 현지 시각까지 작은 동작이 많은데 서로 충돌하지 않고, 같은 이징 두 개(`0.16,1,0.3,1` · `0,0,0.2,1`)로 통일돼 있다.
