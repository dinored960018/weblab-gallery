# REVIEW — LPAS

- 원본: https://lpas.com/ · Awwwards Site of the Day 2026-10-10 (7.24/10, Studio Naam)
- 모작: `KMRV Architecture + Interiors` · 35페이지 · http://localhost:4432/
- 비교 그림: `refs/cmp/*.jpg`(페이지별 원본|모작 11장), 모션 `refs/motion-compare.html`, 상태 `refs/final/states/`

## 왜 상을 받았나

1. **시장 다섯 개가 사이트의 뼈대이자 색이다.** Housing `#625653` · Interiors `#925434` · Higher Ed `#c9d3df` · Civic `#707569` · Commercial `#e3c1aa`. 홈 카드, 시장 페이지 머리, 헤더 알약, 프로젝트 페이지 푸터가 전부 같은 다섯 색을 쓴다. "시장 중심 설계 사무소"라는 한 줄 소개가 화면 구조로 보인다.
2. **홈 첫 화면이 하나의 장면이다.** 프리로더의 L·P·A·S 가 Listen · Plan · Analyze · Shape 로 펼쳐지고, 그 사이 사진이 커져 히어로가 되고, 스크롤하면 시장 카드 다섯 장이 가로로 지나간다. 회사 철학 → 사무실 → 다섯 시장이 4,320px 동안 끊기지 않는다. 수상 페이지 Elements 가 "Homepage loader · Hero Image · Full page menu" 인 이유.
3. **기능이 많지만 전부 같은 손맛이다.** + 원 버튼(아래에서 차오르고 모서리가 25% 로), 화살표 버튼(27→37 늘고 화살표가 바뀜), 하위 링크(5px 밀림)가 사이트 전체에서 같은 300ms `(0,0,.13,.99)` 로 움직인다. 필터·패널·탭·슬라이더가 늘어나도 산만하지 않다.
4. **설계 사무소다운 절제.** 서체 하나(Aeonik 400), 사진 모서리 한 곳만 사선으로 자른 형태, 흰 바탕. 장식은 사진과 시장색이 맡는다.

## 장점

- **시장 알약.** 헤더의 20px 색 칸 다섯 개가 "지금 어느 시장에 있는가"와 "다른 시장으로 가기"를 같이 한다. 현재 칸만 130px 로 이름을 보이고, 다른 칸에 올리면 그 칸이 펼쳐지고 현재 칸이 접힌다. 238×29 안에 내비게이션 다섯 개가 들어간다.
- **공정 카드 고정 가로 스크롤.** 다섯 단계가 세로 스크롤로 차례로 지나가고, 왼쪽 Phases 목록이 위치를 알려준다. 카드를 누르면 같은 화면 위에 패널이 열려 Previous · Next 로 단계를 넘긴다. 긴 공정 설명이 본문을 밀어내지 않는다.
- **카드 모서리 사선.** 오른쪽 아래 한 모서리만 28px 잘린 사진이 사이트 전체의 표식이다. 프리로더 사진, 소식 미리보기, 하이라이트 카드, 공정 카드(오른쪽 위)까지 같은 형태라 로고 없이도 같은 사이트로 읽힌다.
- **드러나는 푸터.** 마지막 사진 구역이 올라가면 어두운 푸터가 아래에서 드러난다(sticky). 끝에 닿았다는 신호가 분명하고, 프로젝트 페이지에서는 푸터가 시장색으로 바뀌어 "다음 프로젝트"와 이어진다.
- **포트폴리오 필터 2단.** Housing 을 고르면 아래에 하위 시장 필터 줄이 생긴다. 큰 분류와 작은 분류를 한 화면에서 고르고, 주소(`?market=`)에 남아 홈의 "See our focus cases" 링크가 바로 걸린 목록으로 온다.

## 단점

- **대비.** 푸터 회색 링크 `#747474`(어두운 바탕 위 3.3:1), 밝은 시장색(`#e3c1aa` · `#c9d3df`) 위 흰 글이 AA 미달. impeccable 첫 실행에서 대비 181건이 이 계열이었다.
- **프리로더가 매번 돈다.** 홈 8~10초, 다른 페이지도 3~5초 어두운 화면. 같은 사이트 안에서 페이지를 옮길 때마다 기다린다. 재방문·내부 이동에서는 건너뛰어야 한다.
- **스크롤 가로채기.** Lenis 가 프리로더 동안 스크롤을 막고(`lenis-stopped`), 히어로는 4,320px 고정. 소개 문장까지 휠을 20번 넘게 굴려야 한다. 시장 카드를 다 보지 않고 아래로 가는 방법이 없다(건너뛰기 링크 없음).
- **팀 사진 40장이 첫 진입에 한꺼번에.** 필터 4개가 있지만 기본이 All 이라 About 이 사진 목록이 된다.
- **소식이 인스타그램 이미지 묶음.** 카드 제목이 전부 "Instagram: 24 Sep 2026" 형식이라 제목만으로 무슨 소식인지 모른다. 홈 목록은 오른쪽 요약 글이 14px 회색 한 줄로 잘린다.
- **공정 카드 본문 3줄 말줄임.** 카드 아래 설명이 세 줄에서 잘려 패널을 열어야만 읽힌다.

## 재현하면서 배운 것

- **"카드 전체 호버로 버튼이 반응한다"는 스크린샷으로는 안 보였다.** 모션 녹화의 서명 비교에서 원본에만 있는 color·top 전환이 나와서 찾았다. 커서가 스크롤 중 카드를 스칠 때만 생기는 동작이다.
- **고정 구간 길이는 뷰포트 높이가 아니라 폭이었다.** pin-spacer 4,320 = 3×1440. 처음에 480vh 로 만들었다가 1440×900 에서 원본과 카드 위치를 같은 스크롤 값으로 재 보고(카드 왼쪽 −14 vs −17) 300vw 로 바꿨다.
- **쌓임 맥락.** 드러나는 푸터를 위해 본문을 z-index 2 층으로 감쌌더니, 그 안의 공정 패널이 헤더(z 800) 아래로 깔려 Close 를 누를 수 없었다. 클릭 테스트가 잡았다. 패널을 body 로 옮겼다.
- **스톡 사진 검수는 원본 크기로.** 작은 밀착 시트에서는 괜찮던 사진 중 세 장이 원본 크기에서 Shell·Waitrose 간판, 사과 로고, "Capitol Towers" 현수막을 드러냈다. 결국 158장 → 117장.

## 어긋난 채로 남은 것

- 히어로가 영상이 아니라 사진 한 장이라 첫 화면의 움직임이 원본보다 적다.
- Lenis 관성이 없어 휠 한 번의 이동이 원본보다 딱딱하다. 카드 가로 이동의 "따라오는" 느낌이 덜하다.
- 프로젝트 상세 사진 배치가 18개 모두 같다. 원본은 프로젝트마다 사진 수·배치가 다르다(6,090 ~ 15,956px).
- 갤러리 사진은 시장별 공용 풀에서 돌려 써서, 다른 프로젝트 상세에 같은 사진이 다시 나온다(한 페이지 안에서는 겹치지 않음, 표지 사진만 머리와 끝에 두 번).
- 서체 Host Grotesk 는 Aeonik 보다 자폭이 약간 좁아 75px 제목 줄바꿈 위치가 다를 수 있다.
- 모션 대조에 빨강 6건(역방향 219ms)이 남았다 — 같은 전환의 커서 타이밍 차이(SPEC 녹화 대조 결과).
