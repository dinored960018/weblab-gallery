- **VIEW MORE · 소셜 링크**: 원본은 자이 매거진 계정. 모작은 각 서비스 첫 화면(새 창).
- **공유**: 원본과 같은 4개(링크 복사 · 페이스북 · X · 기기 공유). 공유 주소는 가상 도메인 `withinh.example`.

## 섹션 순서

- **홈**: 헤더 → WH PICKS(제목·소개·슬라이드) → NEW STORIES(카드 4) → 구분선 → 섹션 대표 카드 4(PEOPLE·DAILY·NOTES·PLACE) → WH TV(베이지 띠, 영상 4) → 안내 상자(사연 · 뉴스레터 · 소개) → 푸터
