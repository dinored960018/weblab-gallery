### 옮기지 못한 것 · 다르게 한 것

- 메뉴 막대 · 하위 메뉴 밑줄 · 단행본 설명 글 이동: 원본은 `width`·`left`·`margin-top` 을 애니메이션한다. 모작은 같은 시간·이징으로 `transform`(scaleX · translate)으로 옮겼다 — 화면 결과는 같고 레이아웃을 다시 계산하지 않는다.
- 검색 상자 폭 40→230(300ms ease-out)은 원본 그대로 `width` 를 애니메이션한다. 테두리가 있는 상자라 scaleX 로 바꾸면 테두리가 늘어나 원본과 달라진다(impeccable `layout-transition` 1건 — 아래 게이트).
- 단행본 목록 두 칸의 폭 전환(원본 `transition: 0.8s cubic-bezier(.645,.045,.355,1)`)은 원본에서도 다른 주소로 넘어가며 새로 그리므로 화면에서 움직임이 보이지 않는다. 모작은 넣지 않았다.
- 모바일: 원본은 같은 주소에서 기기(UA)를 판별해 모바일 마크업을 따로 준다(`refs/mobile--home/00-full.jpg`). 모작은 정적 HTML 이라 `max-width:1100px` 미디어 쿼리 하나로 같은 모바일 화면(51px 고정 헤더 · 왼쪽 서랍 · 단행본 2열)을 낸다. 그래서 1100px 이하 데스크톱 창에서도 모바일 화면이 나온다.
- 원본 영상(회사소개 · 영상자료의 유튜브 7개)은 실존 인물이 나오는 영상이라 쓰지 않았다. 같은 자리에 재생 단추가 올라간 정지 화면을 두었다. 회사소개의 재생 단추는 영상자료 페이지로 이동한다.
