# REVIEW — DIMITO® POSITIVEMIND (디미토) 한국 쇼핑몰

- **어워드**: Awwwards Honorable Mention (2026-02-02) · https://www.awwwards.com/sites/dimito — 수상 대상은 글로벌 스토어, 모작은 같은 디자인의 한국어 쇼핑몰
- **모작**: VEKRA® SNOWSIDE / 베크라 (가상 스노보드 아우터 브랜드) · 116페이지

---

## 왜 상을 받았나

같은 시기 수상한 한국 패션 커머스(앤더슨벨·유노브·노크)가 전부 Shopify 테마를 바탕으로 한 것처럼, 디미토도 구조는 평범한 쇼핑몰이다. 심사가 본 것은 **새로운 구조가 아니라 브랜드 사진을 쇼핑몰 틀 안에서 끊기지 않게 보여 주는 편집**이라고 본다. 투표 점수(Design 7 · Usability 7 · Creativity 7 · Content 7)도 어느 한 항목이 튀지 않는다.

- **가장 위험한 선택**: 홈 첫 화면에 상품이 아니라 **행사 기록 사진**(브레이크 댄스 대회 리캡)을 올리고, 헤더를 그 위에 투명하게 겹친 것. 쇼핑몰인데 첫 650px 동안 가격이 하나도 안 보인다. 통한 이유는 그 바로 아래 1ST DROP 캐러셀이 **같은 회색(#f5f5f5) 바탕의 상품 사진 14장**을 가운데 정렬로 무한 반복해, 화보 → 상품으로 넘어가는 경계가 한 번의 스크롤 안에 들어오기 때문이다.
- **가장 공들인 곳**: 메가 메뉴 네 개. SNOW 메가 하나에 분류 링크 39개와 화보 카드 2장이 들어가는데, 4열 153px · 열 제목 밑줄 1px · 링크 13px #404040 로 통일해 글자가 많아도 표처럼 읽힌다. 열리는 동작은 250ms 동안 6px 내려오며 나타나는 것 하나뿐이고, 헤더 아이콘은 같은 순간 흰색 → 검은색으로 300ms 바뀐다.
- **모작해 보고 알게 된 것**: 원본 CSS 이징은 2,487개가 전부 `ease` 다. 지속시간도 0.15·0.25·0.3·0.4s 네 개뿐이다. 사이트의 정돈된 인상은 화려한 모션이 아니라 **값의 가짓수를 적게 쓴 것**에서 나온다. 섹션 간격도 15 · 24 · 36 · 40 · 72 다섯 값으로 거의 다 설명된다.

## 장점

- **무엇**: 상품 사진 바탕색을 #f5f5f5 하나로 통일하고 카드 비율을 2:3 으로 고정했다.
  **왜 작동하나**: 장갑·고글·재킷처럼 크기가 다른 상품이 한 줄에 섞여도 격자가 무너지지 않는다. 모작에서 바탕이 다른 핀터레스트 사진 44장을 같은 회색으로 맞추고 나서야 원본 목록과 같은 밀도가 나왔다.
- **무엇**: 홈 헤더가 사진 위에서는 투명, 스크롤을 시작하면 바로 흰 바탕으로 고정된다.
  **왜 작동하나**: 첫 화면은 사진 전체를 쓰고, 스크롤한 뒤에는 메뉴·검색·장바구니가 항상 같은 자리에 있다. 판매 기능과 화보를 한 헤더로 해결했다.
- **무엇**: 상세 페이지에서 사진 열은 길게 흘러가고(1023px × 19장) 정보 열(433px)은 화면에 고정된다.
  **왜 작동하나**: 사진을 끝까지 내려 봐도 사이즈 선택과 주문하기 버튼이 항상 화면 안에 있다.
- **무엇**: 장바구니 담기 결과를 페이지 이동 없이 오른쪽 440px 서랍으로 보여 준다.
  **왜 작동하나**: 상품을 보던 흐름이 끊기지 않고, 닫으면 같은 스크롤 위치로 돌아온다.

## 단점

- **무엇**: 본문 기본 글자가 11px 이다(상세 정보, 새 소식 캡션, 로그인 라벨, 장바구니 문구).
  **어떤 문제를 만드나**: 한글 11px 는 획이 뭉쳐 상세 설명 10줄을 읽기 어렵다. 게이트 검사기도 이 크기를 페이지마다 잡는다.
- **무엇**: 필수 옵션 누락·로그인 빈칸을 `alert()` 하나로 알린다.
  **어떤 문제를 만드나**: 로그인에서 아이디·비밀번호가 둘 다 비어도 첫 칸 하나만 알려 주고, 경고창을 닫으면 어느 칸이 문제였는지 화면에 남지 않는다.
- **무엇**: 품절 사이즈를 글자색 #abaeb5 하나로만 구분한다.
  **어떤 문제를 만드나**: #f2f2f2 바탕 위 대비 2.0:1. 색을 구분하기 어려운 사람에게는 품절 표시가 사라진다.
- **무엇**: 홈 분류 타일 아래 250px 빈칸, 26/27 FW PREVIEW 배너의 흰 벽 사진 위 흰 글자.
  **어떤 문제를 만드나**: 빈칸은 섹션이 끝난 것처럼 보여 스크롤을 멈추게 하고, 프리뷰 제목은 사진 명도 77 위라 거의 안 보인다.
- **무엇**: 목록 페이지에 분류 이름·상품 수·정렬이 없다.
  **어떤 문제를 만드나**: 메가 메뉴에서 ‘OUTER · Down’ 을 눌러 들어와도 지금 어느 분류인지 화면 어디에도 쓰여 있지 않다. 200개 상품을 스크롤로만 훑어야 한다.

## 수정안

- **어디를**: 본문 기본 크기
  **어떻게**: 11px → 13px, 행간 15.4 → 20px. 카드 이름·가격(12px)은 그대로 두고 설명문만 키운다.
  **왜 나아지나**: 상세 설명 10줄이 읽히고, 카드 격자 인상은 바뀌지 않는다.
- **어디를**: 옵션·로그인 경고
  **어떻게**: 사이즈 버튼 묶음 아래 ‘사이즈를 선택해 주세요’ 글자 + 붉은 테두리, 로그인은 칸마다 오류 문장(모작 반영).
  **왜 나아지나**: 여러 칸의 문제를 한 번에 보고, 경고창 없이 바로 고칠 수 있다.
- **어디를**: 품절 사이즈
  **어떻게**: 글자색 #6b6e75(4.5:1) + 취소선 + 버튼에 `품절` 읽기 이름(모작 반영).
  **왜 나아지나**: 색에만 기대지 않고 품절을 알린다.
- **어디를**: 목록 머리
  **어떻게**: 사진 격자 위에 분류 이름(14px 700) · 상품 수 · 정렬(신상품/가격) 한 줄, 높이 40px.
  **왜 나아지나**: 현재 위치를 알 수 있고, 200개 목록에서 가격순으로 바로 찾는다.
- **어디를**: 프리뷰 배너
  **어떻게**: 명도 55 이하 사진을 쓰거나 제목 아래 20% 높이에 rgba(0,0,0,.35) 그라데이션.
  **왜 나아지나**: 흰 제목 대비 4.5:1 이상.

## 재현하면서 배운 것

- **그리드 안의 Swiper 는 `min-width: 0` 이 없으면 부모를 끝없이 늘린다.** 기사 페이지 2열(1fr 1fr) 안의 슬라이더가 슬라이드 너비를 전부 더한 폭으로 칸을 밀어 1440px 에서 가로 넘침이 났고, 매장 페이지에서는 같은 이유로 Swiper 가 ‘넘길 게 없다’고 판단해 다음 버튼을 잠갔다(`swiper-button-lock`). 두 증상이 같은 원인이었다.
- **상단 띠를 헤더 밖에 두면 홈 전체가 20px 밀린다.** 원본은 띠까지 헤더(absolute) 안에 있어서 배너가 y=0 에서 시작한다. 섹션 위치를 원본과 표로 맞대 보고서야 찾았다.
- **원본 헤더는 ‘투명 → 흰색’이 두 가지 이유로 바뀐다.** 호버·메가 때(is-light)와 스크롤 시작 때(fixed). 처음엔 호버만 옮겼다가 원본·모작을 같은 스크롤 위치로 찍어 붙여 보고 고정 헤더를 빠뜨린 걸 알았다.
- **사진 바탕 통일은 CSS 곱하기보다 사진에 직접 칠하는 쪽이 낫다.** `mix-blend-mode: multiply` 로 회색을 깔면 화면은 같지만 게이트가 ‘글자 없는 상자 안 사진’을 여백 부족으로 잡았고, 바탕이 흰색이 아닌 사진(그라데이션 배경)은 상자가 비쳤다. 배경색을 측정해 흰색으로 끌어올린 뒤 #f5f5f5 를 곱해 저장하니 둘 다 사라졌다.
- **모바일 메뉴 패널을 화면 밖에 translateX 로만 두면 가로 넘침 검사가 전 페이지에서 걸린다.** 쓰지 않는 패널은 `hidden` 으로 빼고, 열 때만 넣은 뒤 다음 프레임에 이동시켜야 전환도 살고 검사도 통과한다. 패널이 3단으로 쌓일 때 DOM 순서상 부모가 위에 그려져 뒤로 가기 버튼이 눌리지 않는 문제도 기능 테스트에서 잡혔다(z-index 를 단계마다 올려서 해결).

## 어긋난 채로 남은 것

- **목록 수**: 원본 상품 약 200개(1ST DROP 분류) → 모작 44개 전체, 새 소식 50여 건 → 12, 룩북 34 → 14, 컬렉션 기사 사진 수십 장 → 13장. 해당 페이지 문서 높이 7~34%.
- **상품 사진 수**: 원본 상세는 상품당 19장(앞·뒤·착용·디테일), 모작은 같은 상품 사진 1장에서 확대 컷 3장 + 화보 2장. 호버 두 번째 사진도 확대 컷이다.
- **상품 색**: 원본 1ST DROP 은 녹색·보라·뱀피·남색·빨강 재킷이 섞여 있다. 로고 없는 상품 사진을 고르다 보니 모작은 흰색·크림색이 대부분이라 캐러셀의 색 리듬이 약하다.
- **사진 속 사람**: 원본은 모델 얼굴이 나오는 룩북이 중심이다. 모작은 얼굴 없는 뒷모습·고글 컷만 써서 ‘사람이 입은 옷’의 인상이 약하다.
- **서체**: neogroteskessalt → Archivo(wdth 110). 넓은 그로테스크라는 인상은 같지만 ‘R’·‘S’ 끝 처리가 다르다.
- **컬렉션 영상**: YouTube 대신 정지 사진.
- **네이버페이 · 찜 · 톡톡**: 없음.
- **본문 11px**: 원본 그대로 두었다(게이트 `tiny-text` 178건 — SPEC 에 근거).
