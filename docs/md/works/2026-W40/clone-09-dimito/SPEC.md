### 옮기지 못한 것 · 다르게 한 것

- **Swiper**: 원본도 Swiper(구버전) 를 쓴다. 같은 결과를 위해 Swiper 11 (jsdelivr) 을 썼다. 설정값(speed 300, loop, centeredSlides, slidesPerView auto, spaceBetween 15/12, breakpoints 641·1025)은 원본에서 읽은 값.
- **sticky-kit**: 상세 정보 열 고정은 `position: sticky` 로 대체.
- **컬렉션 페이지 YouTube 영상**: 실제 영상을 넣을 수 없어 정지 사진 + 채널 표기 모양 캡션으로 바꿨다. 재생 버튼은 동작하지 않는 컨트롤이 되므로 넣지 않았다.
- **사이즈 표**: 원본은 이미지, 모작은 HTML 표.
- **홈 상단 띠**: 원본은 세로 Swiper 지만 문구가 1개라 움직이지 않는다 → 고정 띠.
