# REVIEW — ELOREA (엘로리아)

- **어워드**: Awwwards Honorable Mention (2026-01-29) · https://www.awwwards.com/sites/elorea

---

## 왜 상을 받았나

Shopify 테마(Broadcast 계열) 위에 만든 커머스라 레이아웃 체계 자체는 새롭지 않다. 모션도 테마 기본값(heroFadeIn 1초, 드로어 300ms)이 전부다. 그런데도 상을 받은 이유는 **첫 화면 6장을 전부 풀스크린 영상·사진으로 채운 편집 순서**와 **‘나의 향 찾기’를 커머스 한가운데 둔 구조**로 본다.

- **가장 위험한 선택**: 홈 첫 4,900px(히어로 6장, 각 100vh)을 상품 그리드 없이 캠페인 이미지로만 채운 것. 커머스 홈에서 첫 상품 카드가 6화면 아래에 나온다. 통한 이유는 히어로마다 버튼이 하나(‘지금 구매하기’)라 결정이 단순하고, 흰 띠 10px 이 장과 장을 끊어 한 장씩 넘기는 잡지처럼 읽히기 때문이다. 투명 헤더가 88% 검정으로 바뀌는 시점(스크롤 36px)도 사진을 최대한 오래 보여 주려는 선택이다.
- **가장 많은 공이 들어간 곳**: 퀴즈. 외부 앱(Tangent)을 쓰지만 문항을 브랜드 말로 다시 썼고, ‘본인/선물’ 답에 따라 이후 질문 주어(당신/그분)가 바뀐다. 결과는 계열 색 그라디언트 카드 한 장 + 추천 3종 + 매장 3곳으로, 검색이 아니라 **대화로 상품에 들어가는 두 번째 입구**를 만들었다. 모작에서도 이 페이지가 가장 오래 걸렸다(7문항 · 휴대폰 단계 · 결과 · 저장 · 다시 하기).
- **모작해보고 알게 된 것**: 이 사이트의 톤은 CSS 가 아니라 **사진 속 병**에서 나온다. 원본 상품 사진은 같은 병(검은 나무 뚜껑 + 반투명 흰 유리)을 매번 다른 소품 위에 올린 스틸 라이프다. 병이 같으니 소품 색만 바뀌어도 그리드가 한 브랜드로 읽힌다. 라벨 없는 스톡 병 사진으로 채운 모작 그리드는 수치가 같아도 병 모양이 제각각이라 브랜드가 안 보인다. 반대로 말하면 원본은 **병 디자인 하나가 디자인 시스템 전체**다.

## 장점

- **무엇**: 폰트 두 벌의 역할 분리 — 한글 제목·본문은 system-ui 700/400, 내비·버튼·탭·가격 라벨은 DM Sans 11~13px.
  **왜 작동하나**: 한글 웹폰트를 한 벌도 안 받는다(웹폰트 요청은 DM Sans 뿐). 크기 단계는 40 / 30 / 20 / 16 / 14 / 11 여섯 개로 적고, 11px 대문자 + 자간 1.1px 라벨이 모든 조작 요소를 한 모양으로 묶는다.
- **무엇**: 카드 그리드 여백 0 + 1px 선.
  **왜 작동하나**: 360px 정사각 사진 4장이 화면 폭을 꽉 채워 매장 진열대처럼 읽힌다. 카드 정보는 가운데 정렬 14px 세 줄(이름 · 향 설명 · 가격)로 끝나서 사진 면적이 카드의 80%다.
- **무엇**: 필터 드로어가 체크하는 즉시 목록을 바꾸고 ‘VIEW N ITEMS’ 버튼 숫자가 따라 바뀜.
  **왜 작동하나**: 드로어를 닫기 전에 결과 수를 알 수 있어 ‘0건’ 막다른 길을 미리 피한다. 가격은 슬라이더와 숫자 입력 두 가지라 정밀 조정이 된다.
- **무엇**: 상품 상세의 발향력·지속력 5단 막대.
  **왜 작동하나**: ‘은은한’, ‘오래가는’ 같은 형용사 대신 같은 척도 위의 위치로 향을 비교하게 한다. 향수처럼 시향이 안 되는 온라인 상품에서 거의 유일한 객관 정보다.

## 단점

- **무엇**: 히어로 사진·영상 위 흰 글자에 덧대기가 없다. 챕터 2(밝은 회색 리넨 영상 위 흰 글씨, `refs/states/home-y900.jpg`)는 글자가 배경에 묻힌다.
  **어떤 문제를 만드나**: 가독성·접근성(WCAG 1.4.3). 영상이 밝은 프레임을 지날 때 제목이 사라진다.
- **무엇**: 공지 바 10.5px 굵은 글씨, 자동 넘김, 정지 버튼 없음.
  **어떤 문제를 만드나**: 무료 배송 기준 같은 필수 정보가 읽는 도중 바뀐다(WCAG 2.2.2). 크기도 조작 요소 권장 하한(11px)보다 작다.
- **무엇**: 카트 개수 뱃지(#ab8c52 위 흰 글자 3.18:1), 캠페인 띠(#c5bdb2 위 흰 18px 본문 1.86:1).
  **어떤 문제를 만드나**: 대비 부족. 특히 캠페인 소개 본문 전체가 이 색 위에 있다.
- **무엇**: 메가 메뉴 항목이 모두 링크인데 ‘프래그런스’ 자체도 링크라 키보드로는 호버 메뉴를 열 방법이 포커스뿐이고, `aria-expanded` 가 원본 헤더 링크에 없다.
  **어떤 문제를 만드나**: 스크린리더 사용자는 하위 메뉴 존재를 모른다.
- **무엇**: 담기 후 소계가 10만 원을 넘으면 증정 선택 모달이 화면을 덮고, 캡처 화면에는 닫기 버튼이 보이지 않는다(`refs/states/search-predictive.jpg`, 담기 직후 캡처).
  **어떤 문제를 만드나**: 조작성. 증정을 원치 않는 사람이 빠져나갈 길을 찾아야 한다.
- **무엇**: 제품 사진 대부분에 브랜드 로고 병이 반복되고, 상품 상세 하단 이미지 섹션 5개가 모두 텍스트 없는 사진이다(상세 페이지 7,400px 중 약 3,700px).
  **어떤 문제를 만드나**: 정보 위계. 스크롤 대비 새 정보가 적다.

## 수정안

- **어디를**: 히어로 글자
  **어떻게**: 왼쪽 아래 55% 검정 → 투명 그라디언트(높이 55%)와 제목 30px 유지(모작 반영). 또는 영상 편집 가이드로 하단 1/3 명도 30 이하 고정.
  **왜 나아지나**: 흰 글자 대비 7:1 이상, 영상 프레임과 무관.
- **어디를**: 공지 바
  **어떻게**: 10.5 → 11px(모작 반영), 호버·포커스 정지(모작 반영), 오른쪽 끝 16px 일시정지 버튼.
  **왜 나아지나**: 2.2.2 충족.
- **어디를**: 뱃지·캠페인 띠 색
  **어떻게**: 뱃지 `#ab8c52 → #7d6435`(5.6:1), 띠 `#c5bdb2 → #7a6e60`(흰 글자 4.97:1, 원본 1.86:1) — 모작 반영.
  **왜 나아지나**: 골드·토프 계열을 유지하면서 AA 통과.
- **어디를**: 메가 메뉴
  **어떻게**: 최상위 링크에 `aria-haspopup`·`aria-expanded`, ↓ 키로 첫 하위 링크 이동, ESC 로 닫고 포커스 복귀(모작 반영).
  **왜 나아지나**: 키보드·스크린리더로 전체 메뉴 구조를 탐색할 수 있다.
- **어디를**: 증정 모달
  **어떻게**: × 버튼 + ESC + 바깥 클릭으로 닫고, 닫으면 같은 기준에서 다시 띄우지 않기(모작 반영). 카트 드로어 안 ‘증정품 선택’ 줄로 나중에 고를 수 있게.
  **왜 나아지나**: 흐름을 막지 않는다.

## 재현하면서 배운 것

- 테마 사이트의 모션은 ‘몇 개를 넣느냐’보다 **같은 1초 heroFadeIn 을 몇 ms 간격으로 거느냐**(0/150/300/450/600)로 성격이 정해진다. 녹화 대조에서 원본 서명 24종 중 20종이 이 스태거와 드로어 두 종류였다.
- 향수 사이트의 상품 정보는 형용사로 채우기 쉽다. 원본 문구의 꾸밈어를 빼고 노트·부향률·발향 거리·지속 시간·원료 산지로 바꾸니 문장이 짧아지고, 퀴즈 결과 카드도 성격 묘사 대신 노트 표가 됐다. 퀴즈 ‘느낌’ 문항(세련되고 포근한…)도 ‘좋아하는 재료’로 바꿔야 답이 추천 계산에 실제로 쓰였다.
- `verify-site` 의 가로 넘침 검사는 화면 밖으로 나간 요소를 모두 잡는다. 캐러셀의 잘린 마지막 칸, 화면 밖에서 들어오는 화살표, 1.05배로 대기 중인 사진이 전부 걸렸다. 원본 모양(잘린 칸)을 지키는 것과 검사 통과가 충돌한 첫 사례.

## 어긋난 채로 남은 것

- 상품 사진 통일성(위 ‘알게 된 것’). 라벨 없는 같은 병 사진 세트는 스톡에서 구할 수 없었다.
- 탭 레일: 3.58칸 + 드래그 → 4칸 + 버튼·키보드.
- 히어로·캠페인 영상 → 정지 사진(첫 히어로는 3장 크로스페이드).
- 투명 헤더 로고 교차 페이드(원본 로고 이미지 2장) 없음.
- 예측 검색 결과 화면을 원본에서 못 봐서 레이아웃은 추정(4열 썸네일 목록).
- 소개 페이지 2개 → 1개. 문의 페이지는 원본처럼 안내 문장만(폼 없음).
- 문서 높이 ±15% 밖: 디스커버리 세트 상세 79%, 캠페인 아카이브 81%, 캠페인 83%, 소개 83%, 검색 결과(결과 수 의존).
- 퀴즈 결과 ‘결과 저장하기’의 원본 동작(이미지 저장인지, 문자 발송인지)은 확인 못 했다. 모작은 PNG 내려받기.
