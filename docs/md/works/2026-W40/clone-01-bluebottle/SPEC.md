## 모션

`extract-origin.mjs` + `record-motion.mjs` 실측. 원본은 Dawn 기본값 + Swiper. 쓰는 이징은 셋뿐이다.

| 토큰 (모작) | 곡선 | 쓰는 곳 (원본 실측) |
|---|---|---|
| `ease` | `ease` | 공지·레일 슬라이드 300ms, 메뉴 드로어 200ms, 카트 드로어 200ms, 검색 500ms, 버튼 배경 300ms, 아이콘 scale 100ms |
| `--ease-sw` | `cubic-bezier(0.4, 0, 0.2, 1)` | 헤더 숨김/복귀 500ms, 슬라이더 화살표 500ms |
| `--ease-img` | `cubic-bezier(0.25, 0.46, 0.45, 0.94)` | 이미지 페이드 400ms, 카드 호버 이미지 교체 400ms |

`prefers-reduced-motion: reduce` → 모든 transition/animation 0.01ms, 공지 자동 넘김 정지, 포커스 이동 지연 20ms.
