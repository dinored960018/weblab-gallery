## 사이트 구조

- **원본 페이지**: 크롤 9개(`measure.json`) — 홈, `/articles`, `/papers`, `/patents`, `/worksheets`, `/services`, `/inquiry`, `/qna`, `/privacy-policy`(실제로는 404 화면) + 검색 결과 `/search`, 분류별 더 보기 `/searchshowmore` + 영문판 `/en/*`(언어 선택 메뉴, `refs/states/en-home.jpg`, `en-articles.jpg`).
- **사례 상세는 페이지가 아니라 모달**이다. 카드를 누르면 URL이 그대로인 채 라이트박스가 뜬다(`refs/states/article-detail-top.jpg`, `article-modal-scroll*.jpg`, `article-modal-end.jpg`). ESC·바깥 클릭·× 로 닫힌다(`article-modal-after-esc.jpg`, `-after-outside.jpg`).
- **논문 제목 → doi.org, 특허 제목 → patents.google.com**(외부, 새 탭). 종 썸네일 → lib.mimic.us(외부). **교육 자료 카드 → lib.mimic.us/mir…**(별도 사이트, `refs/states/worksheet-detail-*.jpg`).
- **재현 페이지**: `build.mjs` 가 생성한 **30페이지**(한국어 15 + 영문 15). `href="#"` 0개.

원본 대비:
- 논문·특허 제목은 가상 자료라 DOI·특허 번호가 없다. 대신 같은 주제의 **Google Scholar / Google Patents 검색**으로 연결했다(외부, 새 탭). 종 썸네일은 lib.mimic.us 대신 **GBIF 종 검색**(실제 학명).
- 교육 자료 상세는 원본이 다른 도메인(lib)이다. 모작은 사이트 안 페이지 3개로 만들고, lib 상세의 편집 레이아웃(큰 세리프 제목 + 오른쪽 사진 + 본문 절 + 노란 머리 카드)을 따랐다. 헤더는 lib 전용 헤더 대신 본 사이트 헤더를 썼다.
- 원본 "Terms & Conditions"는 pro.mimic.us 로 나간다. 모작은 짧은 약관 페이지(`/terms/`)로 연결했다(404로 막지 않기 위해).
- 원본 "패밀리 사이트" 5곳은 서로 다른 서브도메인이다. 모작은 가상 사이트 이름을 붙이고 사이트 안 관련 페이지로 연결했다.

## 모션

`extract-origin.mjs`(곡선·키프레임) + `record-motion.mjs`(녹화) + 요소별 `getComputedStyle` 실측(`animation-timing-function`). 원본은 **Wix 진입 애니메이션**을 쓴다. 전부 `paused` 로 걸려 있다가 **뷰포트에 들어올 때 재생**된다(로드 1.5초 뒤 전부 `paused:0`, 스크롤해서 들어오면 `running` — 직접 확인).

| 이름(원본 키프레임) | 지속 | 이징 (요소 computed) | 모작 |
|---|---|---|---|
| `motion-slideIn` + `motion-fadeIn` | 800(흰개미 섹션 본문) / 1200(푸터 제목) | `cubic-bezier(.645,.045,.355,1)` 둘 다 | `.m-slide` 두 애니메이션 동시(`mSlide` + `fadeIn`) |
| slideIn 키프레임 | clip-path `polygon(0 80%,100% 80%,100% 100%,0 100%)` + `translate(0,100%)` → 전체 | | 같은 값 |
| `motion-foldIn` + `motion-fadeIn` | 1200 | fold `cubic-bezier(.175,.885,.32,1.275)` · fade `cubic-bezier(.25,.46,.45,.94)` | `.m-fold` (`mFold` + `mFoldO`) |
| foldIn 키프레임 | `translate(-50%) perspective(800px) rotateY(90deg) translate(50%)` → `rotateY(0)` | | 같은 값 |
| `motion-floatIn` | 1200 | `cubic-bezier(.445,.05,.55,.95)` | `.m-float` translateY(60px)+opacity |
| `motion-fadeIn`(단독) | 1200 | `cubic-bezier(.445,.05,.55,.95)` | `.m-fade` |
| 내비 글자색 호버 | 400 | ease | 동일 |
| 버튼 배경·테두리·글자 호버 | 400 | ease | 동일 |
| 목록 로딩 카드(`changing_background`) | 반복 | – | `.skel` 1.5s 반복, 로드 후 약 0.4초 표시 |

스크롤 연동 transform/opacity는 없다("모션 곡선 — 없음"). 대신 **sticky 레이어**로 움직임이 생긴다(아래 타임라인 2).

## 재현 난이도 메모

1. **sticky 두 겹**: 흰개미 섹션은 왼쪽 글 블록이 오른쪽 두 번째 사진 구간까지 붙어 있어야 흰 카드와 다크 카드가 같은 높이(2978)에 선다. 처음에 행을 둘로 나눴다가 어긋나서 한 격자로 다시 짰다.

3. **진입 애니메이션**: 원본은 slideIn 과 fadeIn 을 한 요소에 동시에 건다. 녹화 비교에서 fade 가 빠진 것을 보고 짝을 맞췄다.
4. `body data-lang` 과 언어 버튼 `data-lang` 선택자가 겹쳐 모든 클릭이 언어 메뉴를 여는 버그를 기능 테스트에서 잡았다(버튼은 클래스로 선택).
