## 네 가지 체와 각각의 자리

### 1. 명사종결 — 라벨·메뉴·제목·섹션 헤드 (50~78%)

가장 많다. 조사를 떼고 체언으로 끊는다.

```
당신 근처의 당근          ← 히어로 카피도 명사로 끝난다
몇 번만 누르면 끝나는 송금
고객상담의 80%를 자동화하는   ← 다음 줄로 이어지는 수식구
지금 뜨는
앱으로 보기
```

**패턴**: 수식구 + 체언. 동사를 쓰더라도 `-는/-한` 관형형으로 만들어 명사를 꾸민다.
**주의**: `~하기`(할인 받기, 앱으로 보기)는 CTA 버튼의 기본형이다.

### 2. 해요체 — 기능 설명과 권유 (6~16%)

토스와 배민이 16%로 가장 높다. **주어를 생략하고 짧게 끊는다.**

```
금액만 입력하면 끝나요.              ← 토스. 12자
이자 받는 날까지 기다릴 필요 없어요.
계좌 잔액이 부족하면 알려줘서 연체되지 않게 막아드려요.
내가 찾던 맛집 배민엔 다 있어요!      ← 배민. 느낌표
한겨울까지 나만의 스타일을 완성해요.   ← 29CM. 청유에 가까움
```

**토스식 특징**: `~해드려요`(겸양) 빈발. 사용자를 주어로 두고("내가 선택할 수 있어요") 서비스를 주어로 안 둔다.
**29CM식 특징**: `~보세요/~만나요` — 에디토리얼 청유. 명령이 아니라 초대에 가깝다.

### 3. 다체 — 슬로건과 단정 (1~12%)

채널톡 12%, 배민 10%. **B2B의 확신**과 **광고 카피**에서 갈린다.

```
복잡하지 않습니다                   ← 채널톡. 단정. 반박을 미리 막는다
써보는게 가장 빠릅니다
기업들의 진짜 결과가 있습니다
아낌없이 다- 드립니다.              ← 배민. 옛 광고체 차용
오늘도 가장 앞서 뜨겁게 달립니다.
지금 배민됩니다                     ← 동사화한 브랜드명
```

**주의**: 채널톡의 다체는 `~습니다`로 끝나지만 합니다체(격식)와 결이 다르다. **짧게 끊어 단정하는 용도**다. 길게 늘이면 공문이 된다.

### 4. 합니다체 — 법적 고지와 신뢰 (0~5%)

거의 전부 하단 고지, 결제 보증, 통신판매중개자 문구다. **본문에는 잘 안 쓴다.**

```
당사는 고객님이 현금 결제한 금액에 대해 우리은행과 채무지급보증 계약을
체결하여 안전거래를 보장하고 있습니다.
```

## 업종별 배합

| 업종 | 기본 체 | 특징 |
|---|---|---|
| **핀테크** (토스) | 명사 70 + 해요 16 | 겸양(`~드려요`), 사용자를 주어로, 한 문장 20자 이내 |
| **커머스/마켓** (29CM·오늘의집) | 명사 65 + 해요 8 | `~보세요/~만나요` 청유. 상품명은 전부 명사 |
| **B2C 플랫폼** (배민) | 명사 51 + 해요 16 + 다체 10 | 느낌표, 말줄임(`다-`), 브랜드명 동사화 |
| **B2B SaaS** (채널톡) | 명사 59 + 다체 12 | 단정 + 수치. "80%를 자동화하는" |
| **커뮤니티** (당근) | 명사 78 | 거의 라벨만. 설명을 안 한다 |

## 더미 텍스트 쓸 때 규칙

1. **명사종결을 절반 이상 쓴다.** 메뉴·섹션헤드·카드제목·CTA는 전부 명사나 `~하기`.
2. **문장은 해요체로, 20자 안쪽.** 주어를 생략한다.
3. **슬로건만 다체로 끊는다.** 한 페이지에 한두 개.
4. **합니다체는 푸터 고지에만.**
5. **업종을 먼저 정하고 배합을 고른다.** 핀테크 더미에 배민식 느낌표를 섞으면 바로 티가 난다.
6. **원본과 글자 수 대역을 맞춘다.** 명사구를 문장으로 바꾸면 길이가 두 배가 되어 레이아웃이 깨진다.
