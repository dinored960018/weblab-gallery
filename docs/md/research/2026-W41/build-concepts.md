> 사용자 승인: 시립 천문대 컨셉 "추천대로 바로" (2026-10-05)

### 이름

- **여늘시립천문대**(가상). 가상 도시 여늘시, 여늘산 서쪽 능선 해발 612 m. 로마자 `yeoneul`. 폴더 `studio/2026-W41-yeoneul/`, 포트 4433
- 이름 확인(2026-10-05 웹 검색): `"여늘" 천문대 OR "여늘시" OR "여늘산"`, `"여늘"` → 같은 이름의 도시·산·천문대·상호 없음. 먼저 본 '가늠재'는 결과가 없었지만 '가늠'이 일반어라 버림
- 실존 천문대(송암·별마로·국립청소년우주센터 등)·지자체 이름과 로고, 한국천문연구원 브랜딩을 쓰지 않는다. 푸터·예약·관측 지수 페이지에 "가상의 천문대, 기상값·잔여석은 지어낸 것, 예약은 전송되지 않음"을 밝힌다
- 하늘(별·행성·달)은 **실제 하늘을 계산한다.** 관측지는 북위 36.9°, 동경 128.3°(가상 지점이지만 한반도 중부 위도). 기상값과 광공해 값만 지어낸다

### 한 줄

오늘 밤(2026-10-05) 관측이 되는지 — 구름·달·하늘 밝기로 낸 시간대별 관측 지수 — 와 그 시각에 지평선 위에 있는 천체를 먼저 보여 주고, 관측 프로그램 회차를 예약하게 하는 시립 천문대.

### 기능

- **관측 지수** — 시간마다 `0.40 × 구름 + 0.15 × 달 + 0.15 × 투명도 + 0.15 × 시상 + 0.15 × 하늘 밝기`(각 0~100), 태양 고도 −18° 이전은 박명 계수를 곱한다. 구름·투명도·시상·SQM 은 가상값(2026-10-05 고정), 달 고도·조명률·태양 고도는 계산값. 등급 A(관측 적합) · B(밝은 천체 위주) · C(달·행성만) · D(관측 어려움). 계산식과 입력값을 표로 공개
- **성도 회전** — 밝은 별 70여 개(J2000 좌표, 세차 보정) + 별자리 선 14 + 행성 4 + 달을 고도·방위로 바꿔 원형(천정 가운데, 북 위)으로 그린다. 슬라이더·시각 단추(21:00 · 00:00 · 03:00)·키보드
- **도감 고르기** — 종류 · 계절(저녁 9시 남중 기준) · 밝기 구간 · 오늘 밤 보임, 정렬(밝기·이름·남중 시각). 주소 복원, 빈 결과 문구
- **예약** — 회차 잔여석, 인원 합 ≤ 잔여석, 어린이 교실은 보호자 1명 이상, 천체사진은 만 16세 이상 확인, 휴대전화 형식, 동의. 제출하면 접수 내용 확인 화면(전송 없음)과 그 회차 잔여석 감소(이 브라우저 안에서만)
- **적색 화면** — 천문대 현장에서 휴대전화를 볼 때 쓰는 야간 화면. 전 화면을 검정 + 빨강으로 바꾼다(관측자의 암순응을 지키는 관례). 이 브라우저에 기억
- 모바일 메뉴 · 공지 펼침 · `href="#"` 없음 · 화면 문구 '고르기'

- **해도 문법** — 수심은 기울인 세리프 숫자 + 작은 소수(7₃), 말린 높이는 밑줄, 육지 이름은 바로 선 대문자 자간, 물 이름은 기울임. 등심선 · 수심 색층은 해안선 경로를 굵게 그은 선(stroke)으로 만들어 거리 = 수심이 되도록
- **레이아웃: 해도 한 장** — 페이지 양옆과 그림 둘레에 해도 테두리의 흑백 눈금 막대(경위도 눈금). 그림은 이중 테두리(neat line) 안에. 카드 · 그림자 · 둥근 모서리 없음
- **신호기 색 규칙** — 빨강 · 노랑 · 파랑은 국제 신호기 안에서만. 깃발은 실제 뜻이 맞는 곳에만(A 잠수, B 위험물 · 급유, G/H 도선, Q 검역). 글자 · 배경 · 버튼에 신호기 색 안 씀
- 운행표(CORRIDOR)와 겹치지 않게 표는 요금 한 곳뿐. 나머지는 곡선 · 지도 · 해도 · 줄 목록
- 잣두루(등고선 지형도가 화면 뼈대)와 등심선이 닮는다. 그래서 해도는 Approach 한 페이지에만 두고, 화면 뼈대는 조석 곡선 + 눈금 테두리로 잡았다. 등고선 대신 수심 숫자 · 색층 · 등화 · 부표 · 나침반 장미가 해도의 주 요소
