> **같은 날 사용자 지시로 바뀜:** "창작은 이제부터 항상 AI 상주하고있는 AX /DX 성격의 사이트를 … 10가지정도를 만든다음에 그 기능들이 들어가게 제작하셈".

- 실존 상호 검색 후 겹치면 제작 단계에서 바꾸고 README 에 남긴다. 실존 자동차 제조사·부품사 이름과 로고를 쓰지 않는다(차종은 "준중형 가솔린" 같은 차급으로만)

### 한 줄

### 기능 (실제 동작)

- **내 차 진단(홈)** — 차급 · 주행거리 · 마지막 교환 시점 입력 → 품목별 남은 km, 지남/곧/여유 판정, 주소 복원
- **주행거리 눈금 띠** — 가로로 끌거나 ←/→ 로 이동(`role="slider"`, `aria-valuetext`), 현재 주행거리 표시선
- **차급 탭**(`aria-selected`, 화살표 키) · **견적 합계**(체크 → 합계 `aria-live`) · **리프트 시간표 예약**(지난 칸 · 찬 칸 비활성, 폼 검증)
- **이력 조회** — 입력 검증, 없는 번호 안내
- FAQ 아코디언 · 모바일 메뉴(배경 스크롤 막음) · 건너뛰기 링크 · `href="#"` 없음

### 레이아웃 — 강한 원색 면 분할 + 가로 주행거리 띠

- 화면을 **안전 노랑 면과 먹 면으로 크게 나눈다.** 카드 없음. 정보는 큰 숫자와 표로만
- 홈 · 교환 주기 페이지의 뼈대는 **가로로 긴 주행거리 눈금 띠**(0~200,000 km). 품목은 띠 위의 눈금 표시
- 제목은 크고 굵은 한국어 고딕으로 화면 폭을 채운다(포스터형)

### 토큰 — 안전 노랑 + 먹 + 흰 (대비는 제작 단계에서 재측정)

| 역할 | 값(초안) |
|---|---|
| 노랑 면 | `#FFD400` |
| 먹 | `#121212` |
| 흰 | `#FAFAF7` |
| 지남(교환 필요) | `#C4200F`(흰 · 노랑 위 대비 재측정) |

노랑 위에 흰 글자를 올리지 않는다.

### 서체

- 지난 창작에서 안 쓴 굵은 한국어 고딕 하나 + 본문 고딕 하나(예: LINE Seed KR · Gmarket Sans · S-Core Dream 중). CDN 응답 확인 후 확정

### 모션 — 둘

1. **주행거리 띠 이동** — 끌기 · 키 입력 시 띠가 따라오고 눈금 숫자가 바뀜(관성 없음, 120 ms ease-out 스냅)
2. **판정 막대** — 진단 결과 품목별 남은 km 막대가 0에서 값까지 채워짐(400 ms ease-out, 40 ms 스태거)

`prefers-reduced-motion` 이면 즉시.

### 사진

Unsplash · Pixabay(기본) — 정비 리프트 · 공구 벽 · 타이어 · 오일 · 작업복 손. 제외: 로고 · 차 상표 · 번호판 · 얼굴 · AI 생성 의심.

### 지난 창작과 무엇이 다른가

| 작업 | 레이아웃 | 바탕 · 색 | 서체 | 모션 |
|---|---|---|---|---|
| 살결정육점(W43) | 본문 + 오른쪽 에이전트 레일 | 숯 + 단면 분홍 | KoddiUD 온고딕 + Nanum Gothic Coding | 에이전트 단계 · 부위 하이라이트 |
| Pellbrook(W43) | 전폭 커맨드 바 + 원장 | 크라프트 + 적갈 | Funnel Display + Funnel Sans | 팔레트 · 원장 줄 |
| Wrenlow(W42) | 고정 구간 가로 이동 길 | 로프 주황 면 | Unbounded + Atkinson | 벽 밑 걷기 · 선 긋기 |
| **경정비소** | **노랑 · 먹 면 분할 + 가로 주행거리 눈금 띠** | **안전 노랑 + 먹 + 흰** | **미사용 굵은 한국어 고딕** | **띠 이동 · 판정 막대** |

**겹치는 점** — 가로로 흐르는 띠는 Wrenlow(세로 스크롤이 가로 이동이 되는 고정 구간)와 이웃이다. 이번 띠는 스크롤과 무관하게 사람이 직접 끄는 눈금 슬라이더이고, 페이지 전체가 아닌 한 구획이다. 원색 면은 Wrenlow 주황 · 볕가락 코발트와 같은 계열이라 노랑과 먹 두 면만 쓴다.
