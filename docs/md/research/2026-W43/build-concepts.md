### 이름

### 한 줄

고기를 고르는 일을 상주 에이전트가 맡는 동네 정육점. 무엇을 할지 세 가지 중 체크하면 에이전트가 부위·중량·가격·픽업 시각까지 정해 준다.

### 기능 (실제 동작)

- **에이전트 패널** — 모든 페이지 오른쪽 고정(데스크톱 400 px), 모바일은 아래 시트. 열기/닫기(`aria-expanded`), Esc, 포커스 복귀. 질문 입력 → 사이트 데이터로 규칙 응답(부위명·가격·영업시간·숙성일), 빠른 질문 칩
- **체크 조회** — 3개 항목 체크(하나 이상) → 단계 3개(재고 확인 · 중량 계산 · 픽업 시각)가 차례로 완료 → 장바구니 초안(수정 가능)
- **부위표** — 축종 탭(`aria-selected`, 화살표 키), 도해 SVG 부위 클릭 ↔ 표 줄 연동, 용도 필터, 가격·숙성일 정렬
- **주문 계산** — 인원 × 용도별 1인 양 → 중량, 두께 → 장수, 매장·시각 슬롯(마감된 슬롯 비활성), 검증 메시지
- **매장 필터** — 동네·영업 중·식당 있음, 결과 수 `aria-live`
- **매장 열기 조회** — "하나라도 해당" 체크 → 3문항 → 결과 판정, 폼 검증
- FAQ 아코디언 · 모바일 메뉴(배경 스크롤 막음) · 건너뛰기 링크 · `href="#"` 없음

### 레이아웃 — 본문 + 상주 에이전트 레일

- 화면을 **본문(왼쪽) + 에이전트 레일(오른쪽 고정)** 으로 나눈다. 레일은 대화 기록이 쌓이는 세로 줄, 본문은 카드 없는 연속 흐름
- 본문 첫 화면은 큰 질문 한 줄 + 체크 3개 + 단추 하나. 그 아래 판매대 현황을 큰 수치(100 g 가격·남은 kg)로 늘어놓는다
- 부위표는 도해(왼쪽)와 표(오른쪽)가 나란히
- 지난 창작에서 쓴 "좌측 고정 눈금자"(저울마루·켜흙)와 반대로 **고정 요소가 오른쪽이고 그 자체가 기능(에이전트)** 이다

## 2. Pellbrook Meat Supply — 영어 (수요일 2026-10-21)

### 이름

- **Pellbrook Meat Supply** — 가상 도시의 업소 납품 도매 정육(레스토랑·호텔·학교 급식). 폴더 `studio/2026-W43-pellbrook/`

### 한 줄

A wholesale butcher where an order agent does the paperwork — tick what applies, and it builds a standing order from cut specs, yields, delivery days and case weights.

### 페이지 (9 + 부위 상세 6 = 15)

| 경로 | 한 줄 |
|---|---|
| `/` | 커맨드 바 + "tick any that apply" 3항목 → 에이전트가 주문 초안을 원장(ledger)에 한 줄씩 적음 |
| `/cuts/` | 납품 규격 목록 — 1차 분할 → 2차 분할, 수율 %, 트림 규격, 케이스 무게, kg 가격 |
| `/cuts/<slug>/` ×6 | 규격서 한 장 — 지방 두께 · 포션 무게 허용 오차 · 포장 · 유통기한 |

| `/traceability/` | 로트 조회 — 로트 번호 → 농장 · 도축일 · 숙성 일수 · 케이스 |

### 기능 (실제 동작)

- **커맨드 팔레트** — ⌘K / Ctrl+K · `/` 로 열림, 명령 검색(화살표 · Enter), Esc 닫힘, 포커스 가둠. "Add 6 kg short rib", "Next delivery for E8" 같은 명령을 사이트 데이터로 처리
- **체크 → 원장** — 3항목 중 하나 이상 체크 → 에이전트가 원장에 줄을 하나씩 추가(수정·삭제 가능), 합계 kg · 케이스 · 금액
- **규격 목록** — 축종·1차 분할 필터, 수율·가격 정렬, 검색, 주소 복원
- **정기 주문 계산 · 배송일 계산 · 로트 조회** — 입력 검증 + 결과 `aria-live`
- FAQ 아코디언 · 모바일 메뉴 · 건너뛰기 링크 · `href="#"` 없음

### 레이아웃 — 원장 한 장 + 위에 커맨드 바

- 화면 맨 위에 **전폭 커맨드 바**(입력창 모양, 늘 보임). 그 아래 본문은 **원장 한 장**: 날짜 · 항목 · 수량 · 단위 · 금액 열이 화면 끝까지 이어지는 줄 목록이 페이지의 뼈대
- 카드 없음. 정보는 원장 줄과 규격서 블록(2단)으로만
- 부위 상세는 규격서 — 왼쪽 큰 사진, 오른쪽 규격 표

### 토큰 — 2도 인쇄: 크라프트 + 소피 적갈 + 먹 (대비는 제작 단계에서 재측정)
