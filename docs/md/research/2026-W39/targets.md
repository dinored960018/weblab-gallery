## 읽는 법

| 열 | 뜻 |
|---|---|
| 페이지 | 홈에서 닿는 내부 링크 수. 6 이상이면 멀티페이지로 본다 |
| 메뉴류 | class에 menu/dropdown/accordion/burger가 있는 요소 수 |
| 탭 | `role="tab"` 또는 class에 tab |
| 모달 | `dialog`, `role="dialog"`, class에 modal/lightbox |
| 폼 | form/input/select/textarea |
| WebGL | 200px 넘는 canvas 존재. Y면 재현 난이도가 크게 오른다 |
| 높이 | 홈 문서 높이(px). 프리로더에 막히면 802 같은 값이 나온다 |

**주의** — 높이가 1000 미만이면 프리로더/게이트에 막힌 것이다. 실측이 안 된 것이므로
직접 열어보고 판단한다.
