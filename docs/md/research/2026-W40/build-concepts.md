# 창작 기획서 — 2026-W40

이번 주 창작 2건. 한국어 1, 영어 1. **사용자 확인 전 초안.**

> 사용자 지시 원문 (2026-09-28):
> **"한국어 웹사이트 2개 영어권웹사이트 두개 창작하나 모작하나씩 그전에 모작할 사이트 주고
> 창작할 사이트도 컨셉기획서 만들어줘"**

지난 창작에서 받은 지적을 먼저 적는다. 소재 선택의 기준이다.

> **"컨셉이 좀 중2병같음 쿨하지 못해 너무 뭐가 많아 좀 더 미니멀하게"** (POUR → HALIDE, 2026-09-22)

그래서 두 건 모두 **내용이 객관적 정보뿐인 소재**를 골랐다. 자랑할 게 없으면 센 척을 할 수 없고,
디자인의 과제가 "정보를 읽히게 만들기"로 좁아진다.
HALIDE(렌즈 카탈로그)와 겹치지 않게 **이번엔 시간 축이 있는 정보**다 — 시간표, 운행표.

## 1. 새물 수영장 — 한국어

가상의 구립 실내 수영장 사이트.

### 한 줄

레인 현황 · 자유수영 시간표 · 강습 접수. 공공 체육시설 사이트를 표와 시간으로만 다시 짠다.

### 왜 이 소재인가

- 한국 공공시설 사이트는 **팝업·공지 게시판·이미지로 된 시간표**로 굳어 있다. 고칠 게 분명하다
- 내용이 전부 수치다. 레인 수, 수온, 시간, 정원, 요금. 꾸밀 말이 없다
- 기능이 많이 필요한 소재다. 요일 탭, 반 필터, 요금 토글, 접수 폼, 휴관일 달력

### 페이지 (13)

```
/                   홈 — 지금 레인 현황 · 오늘 자유수영 · 공지 3건
/free-swim/         자유수영 — 요일 탭 시간표
/classes/           강습 — 반 목록 · 필터(수준·요일·시간대)
/classes/<반>/      강습 상세 ×4 — 기초 · 초급 · 중급 · 상급
/fees/              요금 — 구민/비구민 · 성인/청소년/어린이 토글
/facility/          시설 — 25m 8레인 · 유아풀 · 탈의실 도면
/notice/            공지 목록 — 검색 · 분류
/notice/<글>/       공지 상세 ×2
/apply/             강습 접수 — 폼(검증 메시지)
/location/          오시는 길
```

글의 뼈대(KOREAN §2): 시간표 = 연대기, 강습 = 분류, 요금 = 비교·대조(항목별 표), 시설 = 공간.

### 기능

| 기능 | 어디 | 동작 |
|---|---|---|
| 요일 탭 | 자유수영 | 월~일 탭, `aria-selected`, 방향키 이동 |
| 필터 | 강습 | 수준·요일·시간대 조합으로 목록이 실제로 걸러짐, 결과 수 표시 |
| 요금 토글 | 요금 | 구민/비구민 세그먼트 → 표 금액이 바뀜 |
| 레인 현황 | 홈 | 레인 8개마다 인원·용도(자유/강습). 현재 시각으로 계산 |
| 휴관일 달력 | 홈·공지 | 모달. 바깥 클릭·ESC·닫기 |
| 공지 검색 | 공지 | 제목 검색 + 분류 칩 |
| 접수 폼 | 접수 | 반 선택 · 이름 · 휴대전화 형식 검증 · 동의 체크. 제출은 막고 메시지 표시 |
| 모바일 메뉴 | 전체 | 버거, 열린 동안 배경 스크롤 잠금 |

### 디자인 방향

**타일 줄눈이 레이아웃 그리드다.** 수영장 바닥·벽 타일(한 장 24px, 줄눈 1px)을
배경에 깔고, 모든 요소를 그 격자에 맞춘다. 장식이 아니라 정렬 기준이 눈에 보이는 것이다.

| 역할 | 값 | 비고 |
|---|---|---|
| 타일 | `#F4F6F5` | 바탕 |
| 줄눈 | `#DCE3E1` | 격자선 |
| 잉크 | `#10181B` | 본문 |
| 물 | `#0F6A80` | 링크·선택 상태. 유일한 강조색 |
| 레인 로프 | 초록 `#1F7A45` · 파랑 `#1E56B0` · 노랑 `#E8B92E` | **레인 현황에만.** World Aquatics 시설 규정은 10레인 기준(0·9 초록, 1~3·6~8 파랑, 4·5 노랑). 8레인에 옮겨 1·8 초록, 2·3·6·7 파랑, 4·5 노랑 |

- 서체: **Wanted Sans Variable** 제목·본문, **IBM Plex Mono** 시각·수치(`tabular-nums`)
- 제목 600, 본문 400. 자간 제목 −0.03em, 행간 본문 1.7, `word-break: keep-all`
- 대비는 구현 때 전부 실측한다. 노랑 로프 위 글자는 잉크색만 쓴다

### 모션 — 둘만

| | 무엇 | 어떻게 |
|---|---|---|
| 1 | 레인 현황 | 레인마다 점이 왕복한다. 속도는 그 레인의 용도(강습 반 수준)에서 나온다. `prefers-reduced-motion`이면 멈춘 점 |
| 2 | 페이지 전환 | 문서 간 View Transitions. 강습 카드 → 강습 상세에서 반 이름이 제자리에서 이어진다 |

스크롤 등장 연출은 안 쓴다.

### 이번 주 리서치에서 가져오는 것

- 컨테이너 쿼리 — 강습 카드가 홈(좁은 칸)과 목록(넓은 칸)에서 형태를 바꾼다
- `@view-transition { navigation: auto }` — CSS 내비게이션 매칭 글(08-19)의 현재 지원 범위까지만

### 카피 예시

| 자리 | 문구 |
|---|---|
| 메뉴 | 자유수영 · 강습 · 요금 · 시설 · 공지 · 접수 |
| 히어로 | 25m 8레인 · 수온 28도 |
| 레인 현황 제목 | 지금 레인 |
| 버튼 | 강습 접수 |
| 공지 | 10월 정기 휴관 — 10월 13일(월) |
| 폼 오류 | 휴대전화 번호를 확인해 주세요 |

### 선 긋기

- 가상 시설이다. 실존 구청·시설 이름을 쓰지 않는다
- 요금·정원은 지어낸다. 실제 구립 수영장 요금 대역(성인 월 5~6만 원)에 맞춘다

## 2. CORRIDOR — 영어

가상의 야간 침대열차 운영사 사이트.

### 한 줄

Routes · Cabins · Fares · Timetable · Booking. 운행표 타이포그래피로 짠 야간열차 예약 사이트.

### 왜 이 소재인가

- 열차 운행표는 **타이포그래피의 오래된 교본**이다. 고정폭 숫자, 괘선, 정렬만으로 정보가 선다
- 내용이 전부 사실 형태다. 출발·도착 시각, 정차역, 객실 등급, 운임
- 예약 흐름이 있어 다단계 폼·계산기·비교 탭이 자연스럽게 들어간다

### 페이지 (14)

```
/                     Home — 오늘 출발 · 노선 4개 · 객실
/routes/              Routes — 출발 도시 필터
/routes/<노선>/       Route ×4 — 노선도 · 정차역 시각 · 객실 재고
/cabins/              Cabins — Seat / Couchette / Sleeper 비교 탭
/fares/               Fares — 운임 계산기
/timetable/           Timetable — 전 노선 운행표, 요일 토글
/book/                Booking — 3단계 폼(노선·날짜 → 객실 → 승객)
/help/                Help — FAQ 아코디언
/about/               About
```

도시는 실제 유럽 도시, 운영사·열차명·시각·운임은 지어낸다.

### 기능

| 기능 | 어디 | 동작 |
|---|---|---|
| 출발 도시 필터 | Routes | 칩 선택 → 노선 목록이 걸러짐 |
| 객실 비교 탭 | Cabins | 탭 3개, 방향키 이동, 도면 SVG 교체 |
| 운임 계산기 | Fares | 객실 × 인원 × 할인카드 → 금액 즉시 계산 |
| 요일 토글 | Timetable | 평일/주말 운행표 전환 |
| 3단계 예약 | Booking | 단계 표시, 뒤로 가기, 단계마다 검증 메시지. 최종 제출은 막음 |
| 정차역 모달 | Route | 역을 누르면 플랫폼·환승 정보 모달 |
| FAQ | Help | 아코디언, `aria-expanded` |
| 모바일 메뉴 | 전체 | 버거, 스크롤 잠금 |

### 디자인 방향

**종이 승차권과 역 운행표.** 회백색 용지 위 검정 괘선, 신호등 빨강 하나.

| 역할 | 값 | 비고 |
|---|---|---|
| 종이 | `#EFEFEA` | 바탕. 무채색 승차권 용지 (초안 `#F2EFE6` 은 impeccable cream-palette 에 걸려 교체) |
| 잉크 | `#141517` | 본문·괘선 |
| 잉크 2 | `#55544F` | 보조 |
| 괘선 | `#D6D2C6` | |
| 신호 | `#C21F2B` | **"지금 출발" 한 곳과 오류 메시지에만** |
| 밤 | `#141517` 바탕 / `#EFEFEA` 글자 | 노선 상세의 야간 구간만 반전 |

- 서체: **Barlow** 제목·본문 (초안 Instrument Sans 는 overused-font 에 걸려 교체), **IBM Plex Mono** 시각·열차 번호(`tabular-nums`)
- 시각은 항상 고정폭. 괘선 1px, 그림자 없음, 모서리 0

### 모션 — 둘만

| | 무엇 | 어떻게 |
|---|---|---|
| 1 | 노선도 | 노선 상세의 선이 스크롤에 맞춰 그려지고 정차역이 차례로 켜진다. `animation-timeline: view()` |
| 2 | 페이지 전환 | 노선 카드 → 노선 상세. 노선 막대가 제자리에서 늘어난다(View Transitions) |

### 이번 주 리서치에서 가져오는 것

- SMIL 타이밍 차트(08-20) — 홈의 작은 노선 아이콘은 SVG 안에서 SMIL 로 끝낸다
- 컨테이너 쿼리 — 운행표 카드가 폭에 따라 가로 표 ↔ 세로 목록
- 스크롤 구동 애니메이션 — 노선도 한 곳에만. 기본값으로 깔지 않는다([motion.md](notes/motion.md) 경계)

### 카피 예시

| 자리 | 문구 |
|---|---|
| 메뉴 | Routes · Cabins · Fares · Timetable · Help |
| 히어로 | Amsterdam 21:14 — Vienna 08:52 |
| 섹션 | Tonight · Routes · Cabins |
| 버튼 | Book |
| 객실 | Sleeper, 2 berths, washbasin |
| 폼 오류 | Choose a travel date |

### 선 긋기

- 실존 운영사(ÖBB Nightjet, European Sleeper 등)의 노선명·열차명·로고·배색을 쓰지 않는다
- 운임은 지어내되 실제 야간열차 대역(좌석 €30~, 침대 €120~)에 맞춘다

## 3. 단청 읽기 — 한국어 (오방색 아카이브 재작업)

W39 오방색 아카이브를 **버리고 다시 짠다.** 같은 소재(오방색)를 실제로 쓰이는 자리(단청)로 옮겼다.

> 사용자 지적 원문 (오방색 아카이브):
> **"사이트 내 컨텐츠 부족이랑 뭘 전달하고싶은 사이트인지 잘 안와닿음 디자인이랑 같이 손보긴 해야할듯 다른방식으로"**
>
> 창작 전반:
> **"창작 사이트 만들때 좀 더 다양한 디자인도 시도해봐야함 지금 나온것들은 아무래도 좀 아직 아쉬움"**
>
> 사용자가 고른 방향: **A — "오방색은 단청에서 이렇게 쓰인다. 다음에 궁궐 가면 이걸 보라"**

### 한 줄

**처마 밑 한 칸을 부재별로 뜯어 읽는다.** 기둥은 석간주, 창방 위는 뇌록, 양 끝은 머리초. 다음에 궁궐 가면 이 다섯 곳을 본다.

### 오방색 아카이브에서 무엇이 틀렸나

| 지적 | 원인 | 이번에 |
|---|---|---|
| 콘텐츠 부족 | 색 다섯 장에 방위·계절·안료 이름 한 줄씩. 페이지마다 같은 틀에 값만 바뀌었다 | 부재 11개 · 등급 5등급 8종 · 문양 18개 · 공정 15단계 · 건물 17곳. 전부 출처 있는 사실 |
| 뭘 전달하는지 모름 | "빛깔에는 자리가 있다"는 문장이 추상적이었다. 자리가 실제로 어디인지 안 보여줬다 | 자리가 **건물 부재**다. 도해에서 눌러 본다 |
| 디자인 | 카드 5장 · 괘선 · 가운데 단 | 도해가 화면 전체. 카드·괘선 없음 |

### 왜 이 소재인가

- 오방색이 **실제로 칠해지는 자리**가 단청이다. 색 이론이 아니라 부재·순서·등급이라는 규칙이 있다
- 내용이 전부 사실이다 — 부재 이름, 안료 이름, 공정 순서, 등급, 건물의 중건 연도. 센 척할 틈이 없다
- 읽고 나면 할 일이 생긴다. 궁궐에서 창방 끝을 올려다보고 병머리초인지 장구머리초인지 가려낸다
- **가상 브랜드가 아니다.** 실존 건물 이름이 나오지만 기관 브랜딩·로고는 쓰지 않는다. 사실은 전부 공개 자료(국가유산청 · 한국민족문화대백과사전 · 전통문화포털)에서 가져오고 출처 페이지에 URL을 단다. 없는 사실은 지어내지 않는다 — 가상 수치 규칙(§4-7)의 예외. 소재 자체가 실재 지식이라 지어내면 거짓이 된다
