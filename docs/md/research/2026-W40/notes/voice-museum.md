## 1. 층마다 문체가 정해져 있다

| 층 | 문체 | 실제 문장 |
|---|---|---|
| 관 · 실 요약 (한 줄) | **합쇼체** | "사유의 방은 우리나라의 국보 반가사유상 두 점이 나란히 전시된 공간입니다." |
| 본문 설명 | **해라체** | "사유의 방은 삼국시대 6세기 후반과 7세기 전반에 제작된 … 두 점을 나란히 전시한 공간이다." |
| 유물 이름표 | **명사구** | "헌종의 왕릉을 조성하고 시신을 안장한 과정을 기록한 의궤" |
| 추천 · 목록 제목 | 수식 + 작은따옴표 이름 | "김정호가 만든 대형 전국지도 '대동여지도를 찍어낸 목판'" |

**한 화면 안에서 층이 다르면 문체가 다르다.** 그러나 한 층 안에서는 섞지 않는다.

## 2. 첫 문장은 정의

- "고려1실은 고려(918-1392)가 도읍한 개경과 지방의 문화, 고려 사람들의 생활을 주제로 전시를 구성하였다."
- "분청사기는 회청색 바탕흙으로 만든 그릇에 백토를 입힌 뒤 여러 기법으로 장식하고 유약을 씌워 구운 도자기로, '분장회청사기粉粧灰靑沙器'라는 학술 명칭의 줄임말이다."

"X는 ~한 Y이다 / ~로, ~이다." 무엇인지부터 말하고, 이어서 언제·어디서·무엇으로.

## 3. 용어는 나온 자리에서 푼다

- 한자를 붙여 쓴다(괄호 없이): 반가사유상半跏思惟像 · 문벌門閥 · 철소鐵所 · 자기소瓷器所
- 연대는 괄호: 고려(918~1392)
- 처음 나온 말은 같은 문장이나 바로 다음 문장에서 뜻을 준다. 따로 용어집으로 미루지 않는다

## 4. 흐름 — 배경 → 구체 → 볼 수 있는 것

"만월대에서 출토된 기와, 전돌 같은 유물부터, … 다양한 전시품을 만날 수 있다. 그리고 … 유물들을 통해 … 지방 문화를 소개한다. 또한 … 유물들도 전시하고 있다."

- 잇는 말: **그리고 · 또한 · 아울러** — 문단 안에서 사실을 쌓는다
- 끝맺는 말: **~을 엿볼 수 있다 · ~을 만날 수 있다 · ~을 소개한다 · ~로 구성하였다 · ~을 전시하고 있다**
- 문장 길이 40~90자. 짧게 끊어 나열하지 않는다

## 5. AI 같다고 느껴지는 것 — 박물관 글에 없는 것

단청 읽기 초안에서 걸린 모양들이다.

| AI 같은 모양 | 예 (초안) | 박물관식 |
|---|---|---|
| 명사로 뚝뚝 끊은 조각 나열 | "병머리초. 계풍은 뇌록 단색." | "궁궐 창방에는 병머리초를 넣고, 가운데 계풍은 뇌록 한 색으로 칠한다." |
| 화면 조작 안내를 본문처럼 | "부재를 누르면 그 자리로 다가가 칠과 문양을 보여 준다." | 본문에서 뺀다. 조작 안내는 버튼·라벨로 |
| 독자에게 행동 지시 | "다음에 궁궐에 가면 … 이 순서로 본다." | "궁궐 전각 처마 밑에서 먼저 눈에 들어오는 다섯 곳이다." |
| 숫자 + 명사 한 줄 요약 | "건물 열일곱 곳. 자료에 남은 단청 사실만." | "문헌과 공개 자료에 단청 기록이 남은 건물 열일곱 곳을 모았다." |
| 가운뎃점으로 이어 붙인 목록 문장 | "머리초 · 휘 · 금문 · 별화 · 주의초 · 마구리 문양 열아홉." | "머리초, 휘, 금문, 별화, 주의초, 마구리 문양 등 열아홉 가지를 종류별로 정리하였다." |

라벨·메뉴·버튼·표 머리는 계속 명사형이다(PROTOCOL 5절). **바뀌는 것은 설명문이다.**

## 6. 그대로 두는 것

- 꾸밈어 금지(PROTOCOL 6절)는 유지한다. 박물관 글에는 "화려하고 세련된", "뛰어난" 같은 평가어가 있지만 **옮기지 않는다.** 평가 대신 사실(연대·재료·수량·위치)을 쓴다
- 출처 번호 배지는 유지한다
