## 기능 (실제 동작)

- **공기압** — Berto 15 % 처짐 근사(psi = 153.6 × 바퀴 하중 lb ÷ 폭^1.5785 − 7.17, 뒤 60 % · 앞 40 %), 노면 × 0.93/0.85/0.78, 튜브리스 × 0.92, 타이어 최대 · 후크리스 72 psi 상한 경고. 스테퍼(− / +) 키보드 동작, `?rider=&bike=&width=&surface=&tubeless=&hookless=&max=` 복원
- **살 길이** — `√(a² + r² + R² − 2rR·cos(720°·X/N)) − 구멍/2`, 좌우 따로, 2 mm 재고로 내림, 교차 수 초과 오류, 주소 복원
- **타이어 · 림** — 림 안쪽 폭 × 1.4 ~ × 2.2 범위로 Fits / Too narrow / Too wide와 이유, BSD 목록 검색 + 빈 결과 + 지우기
- **공임 · 수업 고르기** — 갈래 단추(`aria-pressed`) + 검색 / 자리 있는 것만, 결과 수(`aria-live`), 빈 결과 + 지우기, `?cat=&q=` · `?topic=&open=` 복원
- **접수** — 만석 날 비활성, 바퀴 짓기면 바퀴 수 선택이 열림, 금액 즉시 계산(오른쪽 열 고정), 오류 요약(포커스 이동 · 항목 링크로 해당 칸 이동) + `aria-invalid` + `aria-describedby`, 이메일 · 휴대전화 형식 검사, 정상 제출 → "Not booked — nothing was sent" + 내용 요약, "Change booking"으로 값 그대로 복귀, `?service=` 미리 고름
- FAQ `details` · 모바일 메뉴(배경 스크롤 막음, Esc 닫고 단추로 포커스 복귀) · 건너뛰기 링크 · 포커스 링 3 px · `href="#"` 없음

## 모션 — 둘

1. **시트 덮기** — 1024 px 이상 · 높이 700 px 이상에서 `position: sticky`. 시트 높이를 재서 `top = min(0, 화면 높이 − 시트 높이)`로 두어, 화면보다 긴 시트(공임 목록 · 접수 폼)는 끝까지 읽힌 뒤 멈춘다. 덮이는 시트는 다음 시트가 올라오는 만큼 흑연 막이 0 → 0.35(스크롤 연동, rAF). 기획서의 `animation-timeline: view()` 대신 JS 를 쓴 이유: 고정된 시트는 자기 view 진행도가 변하지 않아서
2. **결과 숫자 넘김** — 계산 결과가 바뀌면 새 숫자가 0.18em 아래에서 180 ms `cubic-bezier(0.22, 1, 0.36, 1)`로 올라온다

`prefers-reduced-motion: reduce` → 막 · 숫자 넘김 끔(덮기 자체는 스크롤 그대로라 유지). 확인: 감속 모드에서 1300 px 스크롤 후 `--cover` 전부 0. 스크롤 등장 연출 없음.

### impeccable 처리 내역 (처음 24건 + 1 → 0, 억제 없음)

- `cramped-padding` ×23 — 시트 좌우 여백을 `clamp(16px, 3.4vw, 48px)`로 줬더니 검사기가 0으로 읽음 → 48 / 24 / 16 px 고정값을 미디어 쿼리로
- `all-caps-body` ×1 — 홈 라벨 "In the stands · Thursday 8 October, 09:15"(41자)가 대문자 변환 → 라벨 대문자 변환 해제

### 작업 중 실제로 틀렸던 것

- **§5 와 겹침** — 처음 기획(왼쪽 고정 형광 패널 + 수리 진행 조회)이 같은 날 §5(고정 좌우 분할 + 접수 조회 단계 막대)와 같아서 쌓이는 시트 + 계산기 셋으로 바꿈
- **`[hidden]`이 안 먹음** — `.errs` · `.empty` · `.f-group`의 `display: grid`가 `hidden`을 덮어 빈 오류 상자와 바퀴 선택이 늘 보임 → `[hidden]{display:none !important}`
- **오류 요약 링크 클릭 시 예외** — 코드 치환 중 `$$`가 `String.replace`에서 `$`로 바뀌어 `$('a', box).forEach` → 클릭 테스트가 잡음, 고침
- **슬래시 0** — 위 서체 항목 참고
- **넓은 숫자의 단위가 줄 바꿈**(2,900 bikes a year) → 숫자 폭을 글자 수(`--len`)로 나눠 정하고 줄 바꿈 금지
- **첫 시트가 머리 막대만큼 넘침** → 첫 시트만 높이에서 머리 막대 67 px 를 뺌
- **만석 수업에 "Full" 두 번** → 동작 칸 비움
- 계산기 폼이 시트 바닥에 붙어 위가 빔 → 폼은 제목 아래, 결과는 바닥
- 홈 계산기 견본 "83 / 53"이 두 줄로 깨짐 → "83 psi" + 설명에 앞바퀴 값
