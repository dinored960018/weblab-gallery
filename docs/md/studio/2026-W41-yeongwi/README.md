## 한 줄

몰딩 32종과 유리·매트의 값을 밝히고, 그림 크기를 넣으면 바깥 치수·무게·값·완성일을 계산하며, 캔버스 호수 규격과 거는 높이를 알려 주는 액자·표구 공방.
화면 문법은 전시 벽이다. 전 페이지가 짙은 녹색 벽이고, 페이지마다 대상(액자 사진·호수 사각형·계산 미리보기·벽 도해·약도)을 실제 비율로 행잉 라인에 건다. 제목과 설명은 그 옆에 벽 이름표처럼 붙고, 메뉴는 화면 아래 걸레받이 띠에 있다.

## 이름·소재

- 이름 확인(2026-10-09 웹 검색): `"연귀표구사" OR "연귀액자" OR "연귀 표구"` · `연귀 액자 표구사 상호` → 같은 상호 없음. `"담결동" OR "담결로"` → 같은 지명 없음. 검색 도구가 미국 기준이라 국내 소상공인 등록까지는 확인 못 함
- 실존 액자 체인·몰딩 제조사·유리 회사 이름과 상표 없음. 발(footer)에 "가상의 공방, 값·재고·일정은 지어낸 것, 주문과 신청은 전송되지 않음", 주문 접수 화면에도 "전송되지 않았다"

## 기능 — 전부 실제 동작

- **몰딩 고르기** — 재질 5·색조 5·폭 3 다중 고르기(갈래 안 OR, 갈래끼리 AND) `aria-pressed`, 정렬 5가지, 결과 수(`aria-live`), 빈 결과 + 지우기, `?material=&tone=&width=&sort=` 복원
- **견본 대화상자** — `<dialog>` 단면 치수 SVG, ESC·바깥 클릭·닫기 단추, Tab 가둠, 포커스 되돌림, ←/→ 이웃 견본(보이는 순서대로), `?m=` 복원·정리, "이 몰딩으로 계산"
- **액자 계산** — 직접 입력/호수·판형(방향), 매트 폭·색·아래 여백, 몰딩, 유리. 범위 오류(`aria-invalid`), 영업일 계산(일요일 휴무, 들여오는 유리 +2, 금속박 +3, 긴 변 120 cm 초과 +2), 실척 미리보기, 주소 복원·갱신, 주문·거는 높이로 값 넘김
- **호수 탭** — `role="tablist"`, ←/→/Home/End, 호수를 누르면 도해 강조, `?series=&no=` 복원, 고른 크기로 계산
- **유리 견주기** — 최대 둘, 셋째를 고르면 첫째가 빠짐, `?g=` 복원
- **매트 고르기** — 계열 고르기, 색을 고르면 걸린 액자 매트 색이 바뀜, `?tone=&mat=` 복원
- **거는 법** — 못 높이 = 가운데 높이 + 액자 높이/2 − 줄 꼭대기에서 윗변까지, 벽 재질 탭(키보드), 무게로 도구·개수 판정, 벽 도해 갱신, 계산 화면에서 `?h=&kg=` 받음
- **주문 접수** — 계산 결과 요약, 찾는 날(완성일부터 영업일 10개), 검증 4종 + 오류 요약(포커스 이동·링크로 칸 이동), 확인 대화상자, 접수 화면(전송 없음), 다시 쓰기
- **자주 묻는 것** — 갈래 고르기, `<details>` 펼침, `?cat=&open=` 복원
- **모바일 메뉴**(1240 px 아래) — 걸레받이 위로 펼침, 배경 스크롤 잠금, 첫 링크 포커스, ESC·포커스 복귀
- `href="#"` 없음. `file://` 로 열어도 링크·주소 복원이 이어진다

- copy-rules로 고친 것: "~과 같은 식이다"(R07) → "이 식으로 셈한다" · 62자 FAQ 문장 둘로 · 유리·수선 이름표가 한 문단으로 읽혀 60자를 넘던 것 → 설명을 `<p>` 로 나눔 · 몰딩·호수 목록 단추에 줄 전체가 들어가 10자를 넘던 것 → 단추에는 단면 그림·호수만, 나머지는 단추 밖(클릭 영역은 줄 전체로 넓힘) · 라벨 끝 '다'(R19) · "금색이 도는"(R20) · 쉼표 끊긴 문구(R11)
- check-korean로 고친 것: 발의 합쇼체 두 줄 → 해라체, FAQ "변했어요" → "변했을 때"
- 날짜는 전부 계산값(`assets/calc.js` 하나를 생성기와 화면이 같이 씀)

## 작업 중 실제로 틀렸던 것

- 계산 화면에서 호수 입력 줄이 `hidden` 인데도 보임 — `.calc .row { display: grid }` 가 `[hidden]` 을 이김 → `[hidden] { display: none !important }`
- 행잉 라인 표지("가운데 145 cm")가 액자·호수 도해 위에 겹침 → 왼쪽 여백 안 세로쓰기로
- impeccable `layout-transition` — 미리보기가 width·height·padding 을 전환 → 1 px 층 셋을 `transform: translate() scale()` 로 바꿈. `cramped-padding`(그림 칸 안 글자)도 함께 사라짐
- impeccable `low-contrast` 7건(약도) — SVG 글자는 fill 이 짙은데 상속 color 가 미색이라 탐지기가 매트 위 미색으로 읽음 → 약도에 `color` 지정
- impeccable `em-dash-overuse`(계산 오류 상태) — 빈 값 자리 표시 '—' 11개 → 빈칸·"계산 안 됨"
- verify-site 390 넘침(계산 화면) — 1440 → 390 으로 줄일 때 240 ms 전환 동안 커진 미리보기 층이 문서를 넓힘 → 미리보기 `overflow: hidden`
- 테스트 기대값을 손으로 잘못 셈 — 폭 31 mm 이상을 11종으로 적었으나 8종, 좁음+넓음 15종이 맞음
- 받은 사진의 대부분이 AI 목업이라 Unsplash 보조 검색을 두 번 더 함
