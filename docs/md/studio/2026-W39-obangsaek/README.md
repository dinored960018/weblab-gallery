# 오방색 아카이브

한국 전통 다섯 빛깔(五方正色)의 방위·안료·쓰임을 정리한 창작 사이트.

- 산출물: 정적 HTML 7장. 빌드 없이 더블클릭으로 열린다
- 생성: `node build.mjs` — 데이터에서 7장을 찍는다. 손으로 쓰지 않는다

## 왜 이 소재인가

"누르면 물감처럼 색이 차오르는" 모션을 만들라는 주문이었다.
모션이 장식으로 붙으면 금방 질리므로, **색 자체가 내비게이션인 소재**를 골랐다.
오방색은 다섯 색이 곧 다섯 방위이자 다섯 페이지다. 색을 누르는 행위와 화면이 그 색으로
차오르는 결과가 같은 뜻을 가리킨다.

```
yellow/ 황 黃  석황 石黃   #D9A441  중앙 · 늦여름 · 토

```

## 모션 — 두 개만 크게 쓴다

주문이 "빵빵하되 투머치하지 않게"였다. 큰 모션을 둘로 제한하고 나머지는 눌렀다.

| | 무엇 | 어떻게 |
| --- | --- | --- |
| 1 | **물감 차오름** | 색 링크를 누른 **그 좌표**에서 `clip-path: circle()`이 퍼져 화면을 덮고, 560ms 뒤 해당 색 페이지로 이동 |
| 2 | **먹 ↔ 한지** | 테마 전환 시 `mask-position`을 옮겨 대각선으로 한 번 쓸어낸다 |
| 잔 | 스와치 호버 | 안료가 **아래에서 배어 오르듯** `translateY(101%) → 0`. 페이드 아님 |
| 잔 | 스크롤 등장 | 형제 순서대로 70ms 시차 |

`prefers-reduced-motion`이면 차오름·쓸어내기를 끄고 즉시 이동한다.

## 다크 / 라이트

테마 전환이 소재의 일부다. 임의의 밝기 반전이 아니라 **바탕 재료의 교체**다.

| | 바탕 | 글자 |
| --- | --- | --- |
| 먹 (다크) | `#100E0D` 소나무 그을음. 검정이 아니라 푸른 기가 돈다 | `#EDE7DA` |
| 한지 (라이트) | `#F3EEE2` 닥섬유의 누런 기 | `#1C1A18` |

두 테마 모두 종이 결(SVG 노이즈)을 아주 옅게 깐다.

## 서체

`NotoSerifKR-VF` — 실제 쓰는 **433자만 서브셋**해 woff2로 넣었다.
23.7MB → **174KB**. 가변축(`wght 200~900`)은 유지했다.

```bash
py -m pip install fonttools brotli
# build.mjs 가 assets/_chars.txt 에 사용 글자를 남긴다. 그걸로 서브셋한다
```

## 검수

Playwright로 확인한 것

- 7페이지 × **다크·라이트 양쪽** — 대비 미달 **0**, 가로 스크롤 **0**, 서체 로드 O
- 물감 차오름 — 클릭 중간 상태 `circle(87%)`, 색 `#B33A3A` 일치, 이동 후 덮개 복귀
- 테마 — 전환·`localStorage` 저장·`aria-pressed`·페이지 이동 후 유지
- 페이저 순환, JS 에러 0

## 남은 것

- 모바일 내비가 760px 이하에서 숨겨진다. 버거 메뉴 미구현
- 안료 색상값은 발색 범위 중 한 지점. 시대·산지에 따라 폭이 넓다
