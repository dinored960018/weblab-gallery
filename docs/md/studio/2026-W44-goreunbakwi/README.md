## 기능 (실제 동작)

- **내 차 진단** — 연식 2006~2026, 주행거리 0~200,000, 마지막 교환 km ≤ 지금 주행거리 검증(칸 아래 오류 + `aria-invalid` + 첫 오류 칸 포커스). 연료에 따라 해당 없는 칸 비활성(디젤 → 점화 플러그, 가솔린 · LPG → 연료 필터). 기록 없는 품목은 "주기대로 교환한 것"으로 계산. 판정: 지남 = 남은 km < 0, 곧 = 남은 km ≤ min(주기 20 %, 8,000 km). 예상 시기는 연식에서 낸 월 평균 운행으로. `?c=&f=&y=&km=&l=` 주소 복원 · sessionStorage 보관
- **주행거리 눈금 띠** — `role="slider"`, 끌기(1,000 km 스냅) · ←/→ 1,000 km · Page Up/Down 10,000 km · Home/End, `aria-valuetext` 에 "85,000 km · 에어컨 필터 4,000 km 지남 · 지금 교환 2". 띠 위 품목 표시(다음 교환 km, 겹치면 네 단까지 올림), 결과 · 알림이 실시간으로 바뀜
- **차급 탭** — 교환 주기 · 공임 · 부품값 · 예약 날짜. `aria-selected`, ←/→/Home/End
- **견적 합계** — 체크 · 등급 · 차급 · 연료를 바꾸면 `aria-live` 합계. 엔진오일과 같이 하면 에어컨 필터 · 에어클리너 공임 없음. `?c=&f=&w=id:등급` 복원
- **리프트 시간표 예약** — 지난 칸(11:30 전) · 찬 칸 · 작업 시간만큼 이어서 비지 않은 칸(점심 · 마감에 걸림 포함) 비활성. 작업 시간을 바꾸면 고른 칸이 안 맞을 때 풀고 알림. 오류 요약(건수 + 칸 링크, 링크 → 그 칸 포커스). 접수 시 번호 발급 · 그 칸은 "내 예약"
- **이력 조회** — 숫자 4개 검증, 없는 번호 안내, 예시 3대 링크(`?p=&t=`), "이 이력으로 진단"
- FAQ 아코디언(`aria-expanded`) · 모바일 메뉴(1180 px 아래, 첫 링크 포커스 · Esc · 포커스 복귀 · 배경 스크롤 잠금) · 건너뛰기 링크 · `href="#"` 없음

## AX/DX 기능 10 — 정비 도우미

외부 API 없음. `assets/assist.js` 의 낱말 규칙과 이 사이트의 주기표 · 값표 · 시간표로만 답하고, 판 머리에 "규칙 기반 안내"라고 밝힌다. 저장은 sessionStorage 뿐.

| 1 | 상주 도우미 | 모든 페이지 아래 노랑 띠 `정비 도우미` → 위로 열리는 먹 판. 열기 · 닫기 · Esc · 여는 단추로 포커스 복귀. 대화는 페이지를 옮겨도 유지. 페이지별 빠른 질문 칩(명사형: "지금 교환할 품목" · "엔진오일 값" · "예약 빈칸" …). 띠에 "내 차" 요약 |
