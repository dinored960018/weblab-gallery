# 개킴세탁소 — 창작 (모작 아님)

가상의 동네 묵내동 시장 골목에 있는 세탁소 사이트. 한국어. 2026-10-08(W41 목요일, 한국어 창작).
기획: [`research/2026-W41/build-concepts.md` §5](../../research/2026-W41/build-concepts.md) · 사용자 승인 "일단 제작"

## 한 줄

품목별 세탁 요금과 걸리는 날, 수선 요금을 밝히고, 맡긴 옷의 진행 단계를 조회하고 찾는 날을 계산하게 하는 동네 세탁소.
화면 문법은 **고정 좌우 분할 + 세로쓰기 제목 + 차림표**다. 왼쪽 자주 패널은 모든 페이지에서 고정되고 그 페이지 제목을 세로로 세운다. 오른쪽 분홍 본문의 요금은 표가 아니라 점선 리더 줄이다.

## 이름·소재

- **개킴세탁소**(가상). 개킴 = 옷을 개켜 두는 일. 로마자 `gaekim`
- 이름 확인(2026-10-08 웹 검색): `"개킴세탁소"` · `"개킴세탁"` · `개킴 세탁소 OR 세탁 "개킴"` → 같은 이름의 상호 없음. `"묵내동" OR "묵내리"` → 같은 지명 없음. 검색 도구가 미국 기준이라 국내 소상공인 등록까지는 확인하지 못했다
- 실존 세탁 체인·세제 회사 이름과 상표를 쓰지 않았다. 발(footer)·조회·수거 신청에 "가상의 세탁소, 요금·접수 기록·일정은 지어낸 것, 조회와 신청 내용은 보내지 않음"
- 메일 `otgeori@gaekim.example`. 전화번호 없음

## 기능

- **찾는 날 규칙**(build.mjs · site.js 같은 함수) — 14:00 전 접수는 그날이 첫날, 그 뒤·휴무일은 다음 영업일이 첫날. 첫날부터 영업일로 걸리는 날만큼 센 날 15:00부터. 일요일·10/3·10/5(개천절 대체 휴일)·10/9 제외
- **요금 고르기** — 갈래 안 OR · 갈래끼리 AND, `aria-pressed`, 정렬(갈래·값 낮은·높은·걸리는 날·이름), `?cat=&method=&sort=` 복원, 결과 수 `aria-live`, 빈 결과 + 조건 지우기
- **찾는 날 계산** — 일요일·휴무일·마감 뒤·토요일 마감 안내, `?date=&time=&items=` 복원
- **접수 조회** — 번호 형식(붙임표 없이 7자리도 정리)·뒷자리 검증, 없는 번호·뒷자리 불일치 오류, `aria-invalid`, 결과 제목으로 포커스, 단계 `aria-current="step"`, `?no=&tail=` 복원
- **세탁 기호 대화상자** — `<dialog>` 열기(단추·이름), ESC·바깥 클릭·닫기 단추, Tab 가둠, 닫으면 연 단추로 포커스, ←/→ 와 이전·다음 단추로 보이는 기호 사이 이동(끝에서 처음으로), `?g=&sym=` 복원
- **얼룩 탭** — `role="tablist"`, ←/→/Home/End(끝에서 돈다), `aria-selected`·`tabindex`, `?stain=` 복원
- **펼침**(소재·공지) — `aria-expanded`, 줄 어디를 눌러도 펼침
- **수거 신청** — 그 밖의 동 불가, 날짜에 따라 시간대(평일 저녁 / 토 오전), 수량 스테퍼(0~20, 끝에서 비활성), 어림 금액·20,000원 미만 배달비 3,000원, 오류 요약(링크 → 그 칸 포커스), 확인 대화상자(고치기·신청), 접수 화면, 다시 신청
- **모바일 메뉴**(1024 px 아래) — 배경 스크롤 잠금, ESC, 첫 링크 포커스, 닫으면 단추로 포커스
- `href="#"` 없음. 화면 문구는 '고르기'

## 작업 중 실제로 틀렸던 것

- 세로 제목이 `max-height` 에 걸려 둘째 열로 꺾임(홈 "개킴세탁소"가 두 글자만 보임) → 글자 크기를 `(100vh − 140px) / 글자 수 × 0.9` 로 줄이고 `nowrap`
- impeccable 파일 검사 `low-contrast` 12건 — fixed 로 패널 위에 놓인 세로 제목을 탐지기가 분홍 바탕 위 분홍 글자로 읽음. 억제하지 않고 제목에 패널 색 배경을 줌
- URL 검사 `line-length` ~102자(발 안내문) → 발·주석 문단 폭 38em
- `cramped-padding` — 오류 문구 3 px, 펼침 줄 아래 여백 0 → 6 px · 줄 자체에 14 px
- 편집 스크립트에서 `String.replace` 가 바꿀 문자열의 `$$` 를 `$` 로 바꿔 `$$(...)` 가 `$(...)` 가 됨 → 기호 페이지 스크립트 오류(테스트가 잡음), 고침
- 테스트 기대값을 손으로 잘못 셈(가죽 10일을 10월 26일로) → 달력으로 다시 세어 10월 23일. 대화상자 ESC 뒤 포커스 기대값도 "마지막에 본 기호"가 아니라 "연 단추"가 맞음
- 사진 출처 줄과 공지 단추가 copy-rules R15·R16에 걸림 → 위 한국어 항목
