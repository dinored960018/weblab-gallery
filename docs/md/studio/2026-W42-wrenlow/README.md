## 기능 (실제 동작)

- **벽 밑 걷기(홈)** — 1440 등 901 px 이상 + 감속 설정 없음일 때만 고정 구간이 켜짐(`html.walk-on`). 세로 스크롤 진행률 → 트랙 `translate3d`, 걸은 거리 수치와 막대가 패널 위치에서 보간. 네이티브 스크롤(가로채기 · 관성 없음). 패널 안 링크에 키보드 포커스가 가면 그 패널이 보이도록 페이지를 세로로 옮김
- **토포** — 표의 노선 이름 단추와 사진 위 번호 단추가 같은 선택(`aria-pressed` 둘 다 따라감), 선이 그어지고 카드가 `aria-live`로 바뀜, ↑/↓ 로 이전/다음 노선(포커스 같이 이동), `?route=` 복원
- **노선 고르기** — 등급 두 슬라이더(화살표 키, `aria-valuetext`, 최소 > 최대면 서로 밀어냄), 방식 · 벽 단추(`aria-pressed`), 지금 해 드는 벽만, 이름 검색, 정렬 5종, 결과 수 `aria-live`, 빈 결과 + 지우기(포커스 이동), `?min=&max=&style=&wall=&sun=&q=&sort=` 복원
- **등급 환산** — 체계 · 값 고르면 나머지 넷 + 이곳 노선 수, 한 값이 여러 French 등급에 걸치면 범위(UK 5c → 6b to 6b+)와 줄 둘 강조, 표 첫 칸 단추로도 선택, 주소 복원
- **해와 그늘** — 위도 54.31° N 태양 위치(Almanac 저정밀 식)로 방위 · 고도, 벽 방위 ±85° · 맞은편 테 높이 위면 해, 벽마다 05–21시 띠(5분 간격), BST/GMT 자동, 날짜 범위 밖 오류 + `aria-invalid`, 주소 복원
- **마름** — 비 양 · 그친 날짜 · 시각 → 벽마다 “Dry now” 또는 “Dry by about 12:40”(날이 넘어가면 요일 · 날짜), 스며 나오는 벽은 10 mm 이상에서 +72 h, 범위 밖 비 양 오류
- **줄 길이** — 50/60/70/80 m 단추 → 내려올 수 있는 볼트 노선 수와 못 내려오는 노선 목록(링크), 노선 고르면 필요한 줄 · 퀵드로
- **출입 날짜 확인** — 날짜 → 벽마다 열림/닫힘과 이유
- **완등 목록** — 노선 표 · 목록의 Tick(`aria-pressed`, 보이는 글자 Tick/Ticked), 머리 메뉴에 개수, sessionStorage(막히면 그 페이지 메모리), 피라미드, 개별 해제 · 전부 지우기(포커스 이동)
- FAQ `details` · 모바일 메뉴(배경 스크롤 막음, Esc 닫고 단추로 포커스 복귀) · 건너뛰기 링크 · 포커스 링 3 px · `href="#"` 없음

## 서체

- **Unbounded** 400–800 — 제목 · 벽 이름 · 등급 · 큰 수치
- **Atkinson Hyperlegible Next** 400–700 + 이탤릭 — 본문 · 표 · 폼(바깥에서 휴대전화로 읽는 안내서). 이 서체의 0 은 빗금 0 이다(판독성 설계)
- Google Fonts CSS 200 확인(2026-10-12). 지난 20건 · 같은 날 한국어 §1(Grandiflora One · 고운바탕)과 겹치지 않음

### impeccable 처리 내역 (처음 41건 → 0, 억제 없음)

- `undersized-ui-text` ×15 → 390 px 등급 막대 글자 9.92 px. 모바일에서는 막대를 가로 줄(등급 · 막대 · 수)로 눕혀 0.85rem
- `cramped-padding` ×25 → 탐지기는 `clamp(… vw …)` 여백을 0 으로 읽음. `--pad` 를 40/24/16 px(미디어 쿼리)로, 띠 여백도 고정 px로. 논리 속성(`padding-inline`)도 좌우 속성으로 바꿈. 토포 틀은 사진 둘레에 16 px 먹 여백, 벽 목록 줄은 좌우 20 px, 걷기 구간은 바탕을 패널마다 줌
- `low-contrast` ×1 → 위 수정 중 걷기 바탕을 뺐을 때 눈금 글자가 주황 위 초크(2.5)가 됨 → 눈금 띠에 먹 바탕

- Raven Buttress 사진의 등반자는 멀리서 옆모습이 작게 보인다(얼굴 식별 크기 아님). 요청 시 교체
- 걷기 구간 거리 숫자는 화면 35 % 지점 기준 보간이라 패널 숫자와 몇십 m 어긋나 보일 수 있음
