## 기능 (실제 동작)

- **갈래 탭** — 세탁 · 수선 · 얼룩/소재. `aria-selected`, ←/→/Home/End, 포커스 이동
- **품목 찾기** — 입력하면 줄이 걸러지고 건수 `aria-live`, 0건이면 안내. 탭과 함께 걸림
- **견적** — 담기(검증 1~50) · 수량 ± · 급행 · 가게/수거 · 구역 · 원하는 날 → 합계 · 찾는 날 `aria-live`, sessionStorage 로 페이지를 옮겨도 유지
- **찾는 날 규칙** — 영업일(일요일 · 임시 휴무 11/14 · 12/25 뺌) 기준, 11:00 전 접수는 그날부터 · 뒤면 다음 영업일부터, 찾는 시간 16:00. 세탁 + 수선 같이 맡기면 하루 더. 급행은 값 1.5배(500원 올림) · 하루 당김(1일 품목 · 침구 · 신발 · 손세탁 · 외부 위탁은 급행 없음). 수거는 수거한 다음 영업일부터 셈, 배달은 찾는 날 다음 첫 구역 요일
- **맡긴 옷 조회** — 형식 검증(GC-0000-00 · 숫자 4개) + 오류 요약, 없는 번호 안내, 예시 3건, `?no=&ph=` 주소 복원(처음 면 조회 칸이 이 주소로 보냄)
- **보관료** — 찾는 날 다음 날부터 30일 무료, 31일째부터 접수 한 건 하루 500원 · 상한 15,000원, 90일 장기 보관 · 180일 상의
- **수거 신청** — 구역을 고르면 그 구역 요일의 앞으로 2주 날짜와 시간대만 나옴, 폼 검증(구역 · 날 · 시간대 · 주소 4자 · 휴대전화 형식 · 금액) + 오류 요약(링크 → 칸 포커스)
- 자주 묻는 것 아코디언(`aria-expanded`) · 좁은 화면 「면 색인」 메뉴(1100 px 아래, 첫 링크 포커스 · Esc · 포커스 복귀 · 배경 스크롤 잠금) · 건너뛰기 링크 · 주소 해시로 표의 줄 강조 · `href="#"` 없음

## AX/DX 기능 10 — 도우미

외부 API 없음. `assets/assist.js` 의 낱말 규칙과 `assets/core.js` 의 계산(이 사이트의 요금표 · 영업일 · 보관 규칙 · 구역표)으로만 답한다. 판 머리에 **"규칙 기반 안내 · 이 사이트의 요금표와 규칙으로만 답함 · 전송 없음"**. 저장은 sessionStorage 뿐.

- 수선 사진 견적은 사진을 보지 않는다. 사진은 미리보기만 하고 값은 사람이 고른 옷 종류 · 부위로 계산한다(화면에 "사진은 이 브라우저에서만 보이고 어디에도 올라가지 않습니다"를 밝힘). 표에 없는 조합(셔츠 기장 등)은 "가게에서 보고 정함"
- 도우미는 낱말 규칙이라 표에 없는 질문은 "답할 수 없습니다" + 상담 요청서로 보낸다. 품목 낱말은 조사 앞에서도 찾지만 띄어쓰기가 없는 긴 문장, 사투리 이름은 놓칠 수 있다
- 견적 · 수선 초안 · 수거 신청 · 상담 요청 · 기록 · 대화는 sessionStorage 에만. 탭을 닫으면 사라진다. file:// 에서 페이지 사이 sessionStorage 는 Chromium 에서 이어짐을 확인, 다른 브라우저는 확인하지 않음
- 공휴일은 반영하지 않았다(일요일 · 11월 14일 · 12월 25일 휴무, 12월 24일 · 31일 단축만). 날짜 입력은 브라우저 기본 달력(헤드리스 Chromium 은 영어 자리 표시 `mm/dd/yyyy`)
- 모션 녹화(`record-motion.mjs`)는 하지 않았다 — 두 모션의 지속시간 · 이징은 computed style 과 Playwright 로 확인
- Safari · Firefox 에서 직접 열어 보지 않았다
