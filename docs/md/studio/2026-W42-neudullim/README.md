## 한 줄

412석 실내악홀의 공연 일정과 좌석별 무대 거리·값을 밝히고, 객석 점유율·커튼·반사판에 따라 달라지는 잔향 시간을 계산하며, 대관료와 취소 수수료를 셈하는 공립 음악당.
화면 문법은 공연 프로그램 책자의 **가운데 축**이다. 제목·곡목은 가운데 정렬, 이름-값 목록은 축 왼쪽(이름, 오른쪽 맞춤)과 오른쪽(값)으로 짠다. 페이지마다 같은 자리에 **아치 틀** 하나를 두고 그 안에 사진·좌석 배치도·잔향 곡선·무대 평면도·약도를 넣는다.

- 이름 확인(2026-10-12 웹 검색): `"늦울림" 음악당 OR 홀 OR 공연장` · `"늦울림음악당" OR "희담동" OR "희담로"` → 같은 이름의 공연장·지명 없음(비슷한 것은 대구 '공간울림', 강북 '늦봄음악회'). 검색 도구가 미국 기준이라 국내 등록까지는 확인 못 함
- 실존 공연장·악기 제조사·예매 대행사 이름 없음. 피아노는 길이(274 cm · 227 cm)로만 부른다. 출연자·단체 이름은 지어낸 것, 연주곡은 작곡가 사후 70년이 지난 작품만(작곡가·작품 번호·조성은 손으로 대조)
- 발(footer)에 "가상의 음악당이다. 일정·값·좌석·출연자 이름은 지어낸 것이고, 예매와 신청은 전송되지 않는다", 접수 화면에도 "전송되지 않았다". 메일 `pyo@neudullim.example`, 전화번호 없음

## 기능 — 전부 실제 동작

- **공연 고르기** — 갈래·달 다중 고르기(갈래 안 OR, 갈래끼리 AND) `aria-pressed`, 정렬 4, 결과 수 `aria-live`, 빈 결과 + 조건 지우기, `?genre=&month=&sort=` 복원
- **곡목 대화상자** — `<dialog>`, ESC·바깥 클릭·닫기 단추, 포커스 되돌림, ←/→ 이웃 공연(보이는 순서), `?c=` 복원·정리, 좌석 고르기·신청 링크
- **좌석 배치도** — SVG 412석(부채꼴 배치는 `calc.js` 가 열 간격·좌석 폭·통로에서 계산), 공연 번호로 정한 팔린 자리, roving tabindex(좌석 하나만 Tab), ←/→ 같은 열·↑/↓ 앞뒤 열 가장 가까운 빈자리·Home/End, Enter·Space 고르기, 구역·값·거리(눈높이 1.1 m 포함)·시선 각, `?c=&seat=` 복원, 신청으로 값 넘김
- **환불 계산** — 공연·구역·매수·취소일 → 남은 날·기준·수수료·환불액, 당일·지난 날·매수 범위 오류 `aria-invalid`, 전석 공연은 구역 끔
- **잔향 계산** — 세이빈 식 RT = 0.161 V / (ΣSα + 4mV), 빈 자리↔앉은 자리 흡음률을 점유율로 보간, 커튼 160 m²가 벽을 덮음, 반사판을 걷으면 무대 위 빈 공간 90 m². `?occ=&curtain=&shell=` 복원
- **편성 탭** — `role="tablist"`, ←/→/Home/End, `?set=` 복원
- **대관료 계산** — 달력(월요일 휴관·모두 찬 날·지난 날 비활성, 공연 날은 오후·저녁 자동 막힘), 종류 3·시간대·추가 리허설·악기(조율료 자동)·녹음·비영리 30 %(대관료에만) → 내역·공급가·부가세·합계, 주소 복원, 신청으로 내용 넘김
- **신청** — 예매/대관 전환, 좌석 형식·팔린 좌석·매수·이름·휴대전화·동의 검증, 오류 요약(포커스 이동·링크로 칸 이동) + `aria-invalid`, 확인 대화상자, 접수 화면(전송 없음), 다시 쓰기
- **자주 묻는 것** — 갈래 고르기, `<details>` 펼침, `?cat=&open=` 복원
- **모바일 메뉴**(1100 px 아래) — 배경 스크롤 잠금, 첫 링크 포커스, ESC·포커스 복귀
- `href="#"` 없음. `file://` 로 열어도 링크·주소 복원이 이어진다. 화면 문구는 '고르기'
