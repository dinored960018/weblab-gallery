## 기능 (실제 동작)

- **수종 띠** — 띠마다 `button` + `aria-expanded` + `aria-controls`, 하나만 열림, ←/→/↑/↓/Home/End 로 띠 이동, Esc 로 닫음. 900 px 아래에서는 가로 띠(높이 ∝ 재고)로 누움
- **수종 고르기** — 쓰임 단추(`aria-pressed`) · 검색 · 정렬 → 띠 순서와 개수가 바뀜, 결과 수 `aria-live`, 빈 결과 + 지우기, `?use=&q=&sort=` 복원. 비교는 `?a=&b=` 복원
- **재고 고르기** — 종류 · 두께 · 최소량, 두께를 고르면 그 조각만 남고 수치가 바뀜, 빈 결과 + 지우기, 주소 복원
- **판재 계산** — m³ · board feet(× 423.78) · 무게(밀도, 공기 건조 +6 %) · 두께별 단가 · 대패(£0.85/m, 200 mm 초과 £1.40, 최소 £20, 마감 치수 −5 mm) · VAT 20 %. 범위 밖 입력 `aria-invalid` + 문구 + 담기 비활성. "Add to quote" → 이 탭 sessionStorage, 머리 Quote 단추에 줄 수
- **재단 계획** — 부재 줄 추가 · 삭제(포커스 이동), 첫 맞춤 감소 배치, 톱 폭 · 끝 다듬기, 원장보다 긴 부재 오류(요약 링크 → 해당 칸), 원장별 막대 도면(조각 · 다듬기 · 자투리 mm)
- **나무 움직임** — ΔW = 폭 × 계수(접선/방사) × 함수율 차, 폭 막대 10배 확대(줄면 점선, 늘면 노랑), 12수종 같은 조건 막대
- **견적 요청** — 담은 줄 · 삭제, 가져가기/배송 전환(날짜 ↔ 구역), 만석 · 일요일 비활성, 오류 요약(포커스 이동 · 링크로 해당 칸) + `aria-invalid`, 정상 제출 → "Not sent — this yard is fictional" + 요약, "Edit request"로 값 그대로 복귀
- FAQ `details` · 모바일 메뉴(배경 스크롤 막음, Esc 닫고 단추로 포커스 복귀) · 건너뛰기 링크 · 포커스 링 3 px · `href="#"` 없음

## 모션 — 둘

1. **띠 펼침** — 고른 띠 `flex: 0 0 min(46%, 660px)`, 나머지는 재고 비례로 줄어듦. 480 ms `cubic-bezier(0.22, 1, 0.36, 1)`, 열린 띠의 글은 360 ms 뒤 160 ms 페이드
2. **재단 조각 다시 놓기** — 결과가 바뀌면 조각이 원장 왼쪽 끝에서 제자리로 260 ms, 조각마다 30 ms 시차(WAAPI, transform). 움직임 폭 막대도 같은 곡선(`transform: scaleX`)

`prefers-reduced-motion: reduce` → 둘 다 즉시(클릭 테스트로 transition 0 확인). 스크롤 등장 연출 없음.

### 작업 중 실제로 틀렸던 것

- **§7과 배색 겹침** — 기획서를 덧붙이려 다시 읽어 보니 §7이 먼저 짙은 녹색 + 미색을 잡아 하늘색으로 변경
- **페이지 수** — 기획서에 27로 적었으나 실제 14 + 12 = 26, 기획서를 고침
- **스크래치 폴더 충돌** — 사진을 `scratchpad/raw`에 받다가 다른 에이전트 파일이 섞인 걸 보고 전용 폴더로 옮김(남의 파일은 건드리지 않음)
- **재단 오류 링크 클릭이 사라짐** — 칸에서 포커스가 빠질 때 `change`로 오류 요약을 다시 그려 누른 링크가 교체됨. 클릭 테스트가 잡음 → 문구가 같으면 다시 그리지 않음
- 계산 결과 목록을 `<div>`로 감쌌다가 문자열 치환으로 벗기던 코드 → `dt` · `dd` 직접 생성
- 수종 상세 가운데 단이 사진용 0 여백을 받아 위에 붙음 → 사진이 든 단만(`:has(> img)`) 여백 0
