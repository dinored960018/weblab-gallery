# HALIDE — 신규 디자인 (모작 아님)

시네마 렌즈 렌탈 하우스. 2026-09-22.
[`2026-W39-pour`](../) 를 대체한다.

## POUR 를 왜 버렸나

사용자 지적: **"컨셉이 좀 중2병같음 쿨하지 못해 너무 뭐가 많아 좀 더 미니멀하게"**

맞는 지적이었다. 문제는 장식이 아니라 소재였다.
"다리 밑에 불법으로 콘크리트를 붓는 사람들"은 소재 자체가 센 척을 요구한다.
거기에 폴리스라인 노랑·티커·듀오톤·하프톤·밀도 9를 한 페이지에 쌓았다.
장식만 걷어내도 소재가 그대로면 여전히 중2병이다.

## 소재를 이걸로 고른 이유

렌즈 카탈로그는 **내용이 전부 객관적 수치**다.
초점거리, T스톱, 최단초점, 전면경 지름, 이미지서클, 무게, 조리개 날 수.

자랑할 것이 없고 가진 것을 나열할 뿐이라 센 척이 구조적으로 불가능하다.
디자인의 과제가 "스펙 표를 읽히게 만들기"로 좁아지는데, 그게 미니멀 문제다.

가상의 렌탈 하우스다. 제조사·모델·수치·재고·요금 전부 지어냈고
실존 브랜드를 쓰지 않았다.

## 광학 단면도

렌즈 페이지의 그림은 **장식이 아니라 카탈로그가 실제로 싣는 내용**이다.
슬러그를 시드로 쓰는 결정적 난수로 렌즈군 수(4—6군)와 곡률·두께를 정해서
렌즈마다 다른 그림이 나오고, 같은 렌즈는 항상 같은 그림이 나온다.

사진을 쓰지 않은 이유는 [POUR 에서 겪은 것](#사진-문제)과 같다.
`picsum.photos` 는 seed 의 의미를 읽지 않아 무작위 사진이 온다.
조용한 화면에서는 그 불일치가 더 크게 보인다.
첫 시안의 히어로에는 샌드위치 메뉴판이 걸린 카페 사진이 들어갔다.
덮지 않고 사진을 통째로 뺐다. 단면도는 지어낸 사진이 아니라 도면이라 거짓이 아니다.

## 실제로 동작하는 것

- 예약 폼: 빈 값 `Required`, 형식 오류 `Check the address`, 통과 시 안내. `submit` 차단
- 모바일 드로어: 버거 토글, `aria-expanded` 동기화, `Escape` 로 닫힘
- 내비 현재 페이지 `aria-current`
- 브레드크럼 4단계
- `prefers-reduced-motion: reduce`: 전환·스크롤 동작 전부 정지 (실측 애니메이션 0개)

## impeccable 처리 내역

억제 없이 전부 고쳤다.

- **`overused-font` ×2 — 처음에 Geist + Geist Mono 를 썼다.**
  규칙: "Inter, Roboto, Fraunces, Geist, Plus Jakarta Sans, Space Grotesk 는
  너무 많이 쓰여 더 이상 구별되지 않는다."
  폰트를 바꿔달라는 요청에 지금 AI 가 제일 많이 쓰는 기본값을 고른 것이었다.
  → Schibsted Grotesk + Spline Sans Mono
- `low-contrast` ×4 — `--ink-3 #8b8a83` 가 흰 배경에서 **3.4:1**.
  라벨·캡션·브레드크럼·보조설명 전부 해당.
  → `#6f6e69`, 4.98:1. `--ink-2` 도 `#4a4944` 로 내려 단계 간격 유지
- `tiny-text` — `.cap` 이 11.5px 인데 라벨이 아니라 문장이었다 → 13px
- `cramped-padding` — 드로어 링크가 아래 테두리에 붙음 → `padding-bottom:14px`
- `em-dash-overuse` — 범위 표기에 em 대시를 썼다.
  `24—90mm`, `1968—1974`, `Mon—Fri`, `08:00—18:00` 는 전부 **en 대시**가 맞다.
  → 23개 중 생성물에 남은 em 대시 0개, en 대시 70개

## 작업 중 실제로 틀렸던 것

- **클래스 이름 충돌.** 카드 안에 `.foot` 을 썼는데 페이지 푸터의
  `padding:34px 0 52px` 를 그대로 물려받아 카드 아래 52px 공백이 생겼다.
  `margin-top:auto` 는 특정도로 이겼지만 `padding` 은 그대로 내려왔다 → `.meta` 로 분리
- **note 가 두 번 나왔다.** 단면도 아래로 옮기면서 원본 제거가 안 먹었는데
  `node -e` 안에서 템플릿 리터럴 `${}` 이스케이프가 어긋난 탓.
  모바일 스크린샷에서 발견 → `Edit` 로 다시 제거
- `verify-site.mjs` 에 경로를 넘겼다. URL 을 받는 스크립트다.
  1페이지만 검사하고 `h1=0` 이라고 나온 게 그 탓

## 기술

네이티브 CSS + 바닐라 JS. 프레임워크 없음.
