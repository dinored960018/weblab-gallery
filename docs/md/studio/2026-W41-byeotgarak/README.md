# 볕가락제면소 — 창작 (모작 아님)

가상의 바닷가 고장 늘포읍에서 국수를 해풍에 말려 파는 제면소 사이트. 한국어. 2026-10-07(W41 수요일, 한국어 창작).
기획: [`research/2026-W41/build-concepts.md` §3](../../research/2026-W41/build-concepts.md) · 사용자 승인 "일단 제작"

## 한 줄

면 여섯 가지의 굵기·배합·건조 시간·삶는 시간·값을 밝히고, 삶기 타이머와 주문·공장 견학 신청을 두는 해풍 건조 국수 공장.
화면 문법은 2도 인쇄 포장지다. 전 페이지가 코발트 원색 면이고, 크림은 라벨 면으로만, 주홍은 도장 하나로만 쓴다. 굵기 숫자가 제목보다 크다.

## 이름·소재

- **볕가락제면소**(가상). 볕 + 가락(국수 한 가락). 로마자 `byeotgarak`
- 이름 확인(2026-10-07 웹 검색): `"볕가락"` · `"볕가락" 국수 OR 제면소` → 같은 이름의 상호·제품 없음. `"늘포" 읍 OR 항 OR 마을` → 같은 지명 없음
- 실존 제면소·식품 회사 이름과 상표, 포장 디자인을 쓰지 않았다. 발(footer)·주문·견학 대화상자에 "가상의 제면소, 값·재고·건조 기록·잔여석은 지어낸 것, 주문·신청은 전송되지 않음"
- 메일 `myeon@byeotgarak.example`. 전화번호 없음

## 기능

- **면 고르기** — 재료(밀·통밀·메밀) · 굵기 3구간 · 음식 5, 갈래 안은 OR · 갈래끼리 AND, 정렬(굵기·삶는 시간·100 g당 값·이름), `?mat=&thick=&food=&sort=` 복원, 빈 결과 문구와 조건 지우기
- **삶기 타이머** — 면·음식·인분 → 면 g(1인분 × 인분), 물(100 g당 1 L, 최소 2 L), 시간(3인분부터 한 인분마다 +10초). 시작·멈춤·계속·처음부터, 진행 막대, 단계(넣기 → 찬물 반 컵(찬물 붓는 면만) → 30초 전 → 다 됐다)가 바뀔 때만 `aria-live` 알림. `?noodle=&food=&serv=` 복원. 상세 페이지 작은 타이머는 탭을 따라간다
- **삶는 법 탭** — `role="tablist"`, ←/→/Home/End, `aria-selected`·`tabindex` 따라감. 건조 일지 날짜 탭도 같은 모듈
- **주문** — 수량 ± (재고·20봉 상한), 5만 원 이상 배송비 없음, 제주 63000~63644·울릉 40200~40240 +3,000원, 이름·휴대전화·우편번호 5자리·주소·확인 검증, `aria-invalid`, 오류 요약(링크를 누르면 그 칸으로 포커스), 확인 화면 포커스. 전송 없음
- **견학** — 날짜(잔여 합, 마감은 비활성) → 회차(잔여 / 12) → 어른·어린이, 규칙(어린이만은 불가, 8명 상한, 잔여석 초과), 신청 전 `<dialog>` 확인(ESC·바깥 클릭·닫기 단추, 닫히면 제출 단추로 포커스), 접수하면 잔여석이 이 브라우저(localStorage)에서 줄어든다
- **공지** 갈래(`aria-pressed`) + 펼침(`aria-expanded`) · **가로 줄** 이전/다음(끝에서 비활성, 위치 `aria-live`) · **모바일 메뉴**(1180 px 아래, 배경 스크롤 잠금, ESC, 첫 링크 포커스)
- `href="#"` 없음. 화면 문구는 '고르기'

## 작업 중 실제로 틀렸던 것

- `legend` 에 `float: left` 를 줘서 fieldset 격자의 칸 하나를 차지 → 견학 날짜가 오른쪽 한 줄로, 인원 문구가 글자 단위로 꺾임. float 를 지웠다
- 건조 일지 표 머리와 행의 열을 `em` 으로 잡아 글자 크기가 다른 두 줄이 어긋남 → `rem`
- 공정 축 이름표 높이 4단을 쓰면서 CSS는 3단까지만 둬 "4 걸기"가 "5 건조"와 겹침(impeccable `text-occlusion`) → 4단 추가
- 주문 두 열 높이 차(왼쪽이 첫 화면의 178 %, impeccable `first-viewport-column-overflow`) → 받는 사람 칸을 오른쪽 열로 옮김
- impeccable `cramped-padding` 29건 — `clamp()` 패딩을 탐지기가 0으로 읽음. 억제하지 않고 고정 px + 폭별 변수로 바꿈. 약도 SVG에 안쪽 여백
- 견학 테스트에서 처음 고른 날(10월 13일)의 첫 회차 잔여석이 1석이라 2명 신청이 막혔다(기능은 맞고 테스트 날짜가 틀림) → 10월 22일로 바꿈
- 파비콘 404 콘솔 오류 → 인라인 SVG 파비콘
