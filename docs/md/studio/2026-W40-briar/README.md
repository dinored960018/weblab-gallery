## 한 줄

장미 그래픽 데크와 옷. 연회색 바탕에 제품만 놓고 이름과 가격만 적는 가게.

브랜드 이름 BRIAR = 찔레(가시 있는 들장미). "Briar" 스케이트 브랜드는 검색에서 나오지 않았다(2026-09-30). 세계관은 문장으로 설명하지 않고 제품으로만 보인다 — 가시 줄기 그립테이프, 꽃잎 색 7겹 데크 옆면, 장미를 찍은 휠, 시즌 이름 HIP(로즈힙 · 램프 힙).

## 이미지

- **제품은 전부 직접 그린 SVG** (`src/draw.mjs`). 800×1000 투명 캔버스, 같은 그림자·같은 여백이라 한 벌로 보인다. 판 색은 페이지 CSS 가 깐다
  - 장미 그래픽 다섯 가지: 위에서 본 장미(꽃잎 고리 5겹을 계산으로 배치) · 옆에서 본 장미(감싸는 꽃잎 3장 + 눌러 붙인 윗면) · 가시 줄기(베지어 곡선을 따라 가시를 번갈아 배치) · 떨어진 꽃잎 · BRIAR 모노라인 글자(패스로 직접)
  - 데크는 바닥 · 윗면(샌드페이퍼 노이즈) · 그래픽 확대 · 옆면 7겹, 옷은 앞 · 뒤 · 앞 프린트 · 뒤 프린트 컷
- **룩북·홈·소개 사진은 Pinterest 21장** (`assets/photos/credits.json`, 핀 주소 21건 전부 핀 페이지에 해당 이미지가 있는지 확인함). 검색어 5개(스케이트 · 장미 정물 · 콘크리트 스케이트장 · 장미 정원 · 거리 인물)로 60장을 받아 21장만 남겼다
  - 뺀 것: 브랜드 로고·글자 프린트 옷(skate-01 · 10, portrait-05 · 06 · 11), 가게 간판·그래피티 글자(skate-06 · 07 · 11, spot-08, portrait-01 · 07 · 12), 잡지 지면(spot-04, garden-01 · 04 — Dior 로고), 사진 여러 장을 붙인 것(skate-03), AI 렌더로 보이는 장미·정원 사진 대부분
  - 사진 속 옷은 BRIAR 제품이 아니다. 그래서 기획서의 "입은 제품 링크"는 빼고 시즌 제품 4개를 붙였다

## 남은 것

- 사진은 Pinterest 라 라이선스 미확인. 요청 시 스톡으로 교체
- 주소·전화·매장은 가상. 약도는 실제 도로 이름(아차산로·성수이로)을 쓰지만 축척·위치는 지어낸 것
- 회원 가입 · 비밀번호 찾기 페이지는 만들지 않았다(링크도 두지 않음)
- 옆에서 본 장미는 꽃잎 3장 구조라 단순하다. 데크 그래픽을 더 늘리면 손그림 결을 더 넣을 여지가 있다
- 가방 페이지의 줄 금액(수량 × 단가)과 오른쪽 단가가 수량 1일 때 같은 값으로 두 번 보인다
- 커밋 · 갤러리 갱신(`build-index.mjs` · `publish.mjs`)은 하지 않았다
