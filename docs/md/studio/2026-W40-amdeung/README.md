## 한 줄

필름 10종마다 현상 방식·스캔 해상도·가격·작업 일수를 밝히고, 접수(가격 즉시 계산)와 작업 조회를 하는 현상소.

## impeccable 처리 내역

처음 41건. 억제 없이 값으로 고쳤다.

- `low-contrast` ×16 — 건너뛰기 링크가 종이색 바탕인데 전역 `a:hover` 빨강을 받아 2.7:1 → 건너뛰기 링크 hover 는 바탕색 글자. `.btn:hover` 종이색 면도 빨강 테두리·글자로 바꿈
- `cramped-padding` ×20 — 스트립·맞춤 스트립 상자에 필름 베이스색을 깔아 칸이 상자 가장자리에 붙어 보임 → 베이스색은 칸에만. 홈 순서 4칸·안내 목차가 `gap: 1px` + 선색 바탕으로 괘선을 만들던 것 → 링크 자체에 테두리. 작업판 첫 칸 왼쪽 여백 0 → 24px
- `wide-tracking` ×1 — 한글이 섞인 머리 글자 0.06em → 0.04em

## 작업 중 실제로 틀렸던 것

- **탭 패널 셋이 한꺼번에 보임.** `.tp { display: grid }` 가 `hidden` 을 이김 → `[hidden] { display: none !important }`
- **`form.name`** 이 이름 입력칸이 아니라 폼의 name 속성을 돌려줌 → id 로 찾음
- 이름·주소 입력칸에 `type` 이 없어 입력칸 스타일이 안 먹음 → `type="text"`
- 홈 탭 "흑백 흑백" (공정 코드와 이름이 같음) → 같으면 코드 생략. 상세 머리 "흑백 · 흑백" → `ISO 3200 · 흑백 현상`
- 조회 예시 AD260930-003 이 제목은 "현상 대기"인데 접수 칸이 '진행 중' → 접수 끝남, 현상 칸 '차례 기다림'으로
- 추석이 2026-09-24~26 이라 처음 잡은 예시 주문 날짜(9/24·9/26 접수)가 휴일과 겹침 → 날짜를 다시 잡고 공휴일을 영업일 계산에 넣음
- 가격 SVG 라벨이 viewBox 축소로 약 8px → 21 단위(화면 약 13px)
- 390 에서 현상 방식 탭이 넘쳐 E-6 가 잘림 → 간격 줄임, 넘침 0
- 390 접수에서 합계가 폼 맨 아래에만 있음 → 아래 붙는 합계 막대
- 탭 패널 4컷 한 줄이 작아 오른쪽 표 옆이 비어 보임 → 2컷 × 2줄

## 사진

`fetch-stock.mjs` Pinterest 7회 검색(색 거리 · 흑백 · 슬라이드 · 중형 · 정물 · 바다 · 정사각). **받은 98장 중 40장 사용**, 58장 버림.

- 버린 이유: 얼굴이 주 피사체(인물 사진 대부분), 간판·글자(CAFE · CLEANERS · 낙서), **필름 상표 가장자리 인쇄·포장**(KODAK · FUJI 가 찍힌 컷 10장 넘게), 워터마크(© · 500px), 두 장 이어 붙인 사진, 필름 스트립 자체를 찍은 사진, 즉석 사진 테두리, **AI 생성으로 보이는 정물 14장 전부**
- 쓰는 곳: 35mm 컬러 16 · 흑백 9 · 슬라이드 7 · 정사각(120) 8. 전부 한 곳 이상에서 쓰임(미사용 0)
- 긴 변 1100px, JPEG 80%로 줄임(8.6MB → 5.1MB). `assets/photos/credits.json` 에 핀 이미지 주소·검색어·라이선스 미확인 표기. `w`·`h` 는 줄이기 전 원본 크기
- 사진마다 한국어 대체 텍스트(피사체 설명)
- 프레임·퍼포레이션·가장자리 인쇄는 전부 CSS/SVG 로 직접 그림. 사진 안에 필름 테두리가 찍힌 컷은 쓰지 않음

## 한계 · 안 한 것

- 접수·결제·문자 발송은 연결하지 않았다. 화면에 "연습용 사이트"라고 밝힘
- 완료 예정일은 E-6 의 화·금 약품 일정을 계산하지 않는다(일수만 센다). 가격 페이지·조회 예시 메모에만 적음
- 공휴일 목록은 2026년 9~12월만 들어 있다
- 작업판 숫자는 9월 30일 15:00 고정값(실시간 아님)
- Safari·Firefox 에서 직접 열어보지 않았다. `linear()` 이징과 컨테이너 단위(`cqi`)를 못 쓰는 오래된 브라우저에서는 현상 곡선이 직선이 되고, 맞춤 스트립 칸 크기가 깨질 수 있다
- 터치 기기에서 직접 끌어 보지 않았다(터치는 브라우저 기본 가로 스크롤)
- Pinterest 사진은 라이선스 미확인. 요청이 오면 `--source stock` 으로 바꾼다
