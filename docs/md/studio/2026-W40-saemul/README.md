# 새물 수영장 — 신규 디자인 (모작 아님)

가상의 구립 실내 수영장. 2026-09-28.
기획서: [`research/2026-W40/build-concepts.md` §1](../../research/2026-W40/build-concepts.md)

- 산출물: 정적 HTML 14장. 더블클릭(`file://`)으로도 열린다. 링크는 전부 상대 경로
- 생성: `node build.mjs` — 데이터에서 14장을 찍는다. 손으로 쓰지 않는다

## 왜 이 소재인가

지난 창작(POUR)에서 받은 지적: **"컨셉이 좀 중2병같음 쿨하지 못해 너무 뭐가 많아 좀 더 미니멀하게"**

HALIDE 때와 같은 결론이다. 장식을 걷어내는 것보다 **센 척할 것이 없는 소재**를 고르는 게 먼저다.
수영장 사이트의 내용은 전부 수치다. 레인 수, 수온, 시각, 정원, 요금.
꾸밀 말이 없으니 디자인의 일이 "시간표를 읽히게 만들기"로 좁아진다.

한국 공공 체육시설 사이트는 팝업·게시판·**이미지로 된 시간표**로 굳어 있다.
시간표를 이미지가 아니라 표로, 레인 용도를 글이 아니라 계산으로 바꿨다.

가상 시설이다. `새물구`·`새물역`·`새물로` 모두 지어낸 이름이고, 요금·정원·인원도 지어낸 값이다.
요금은 실제 구립 수영장 대역(성인 강습 월 4~6만 원)에 맞췄다.

## 격자 — 타일 줄눈이 레이아웃이다

바닥 타일 한 장 24px, 줄눈 1px. 배경에 깐 줄눈이 곧 정렬 기준이다.

- `.wrap` 폭을 **48px 배수**로 잘라(`round(down, 100% - 30px, 48px)`) 화면 가운데 줄눈에 좌우 대칭으로 건다.
  배경은 `background-position: calc(50% + 12px) 0` 으로 가운데에서 24px 간격
- 표·목록·폼 같은 블록(`.blk`)은 바탕을 타일색으로 채우고 **위·왼쪽 선만** 긋는다. 아래·오른쪽 선은 바깥 줄눈이 긋는다
- 칸 선은 `border` 대신 `box-shadow: inset` — 테두리가 1px 를 먹으면 행 높이가 24px 배수에서 어긋난다
- 글줄은 24px 한 칸. 표 칸 = 위아래 12px + 24px = 48px
- 글이 줄바꿈되며 생기는 자투리는 `site.js` 가 `ResizeObserver` 로 블록 아래 여백을 늘려 24px 배수로 맞춘다
- 시설 도면·약도는 **1칸 = 1m**. 경영풀 25m × 16m = 25칸 × 16칸

실측(Playwright, 10개 페이지 × 1440·390): 블록의 x·y·높이가 줄눈에서 **0.6px 넘게 어긋난 곳 0**.

## 데이터와 계산

`assets/pool.js` 하나에 반·운영 시각·휴관일·레인 계산이 다 있다.
브라우저는 `<script>` 로, `build.mjs` 는 `import()` 로 **같은 파일**을 읽는다. 시간표 페이지와 홈 레인 현황이 어긋날 수 없다.

- 운영 — 평일 06~22시, 토 07~18시, 일 09~17시. 한 부 = 50분 수영 + 10분 휴식. 평일 13시 부는 수질 점검
- 반 17개가 요일·시각·레인을 가진다. 그 부의 나머지 레인이 자유수영
- 자유 레인 구분 — 1 걷기 · 2·3 초보 · 4~6 중급 · 7·8 상급
- 휴관 — 매월 둘째 월요일, 1월 1일, 설·추석 연휴
- 인원 — 강습 레인은 등록 인원을 둘로 나눈 값. 자유 레인은 시간대 혼잡도 × 날짜·시각·레인을 시드로 한 결정적 난수. **추정치라고 화면에 적었다**

`?t=2026-10-01T07:20` 을 붙이면 그 시각으로 계산한다(검수용).

## 모션 — 둘만

| | 무엇 | 어떻게 |
|---|---|---|
| 1 | 레인 점 | 레인마다 점 하나가 25m 를 왕복한다. 속도 = 그 레인 용도의 25m 기록(걷기 13초 · 초보 9 · 중급 6.5 · 상급 5, 강습 기초 11 · 초급 8.5). `ease-in-out` 이라 벽에서 느려진다(턴). 이동 거리는 `100cqw` — 트랙이 컨테이너다. 수영 중이 아니면(휴식·점검·휴관·운영 전후) 점이 없다 |
| 2 | 페이지 전환 | 문서 간 View Transitions(`@view-transition { navigation: auto }`). 강습 카드의 수준 이름을 누르면 **그 카드의 이름에만** `view-transition-name: level-title` 을 주고, 상세 페이지 `h1` 이 같은 이름을 받아 제자리에서 이어진다. 머리(`hd`)는 이름을 따로 줘서 움직이지 않는다 |

`prefers-reduced-motion: reduce` — 점 애니메이션 없음(점은 레인마다 다른 자리에 멈춰 있다), 문서 전환 `navigation: none`.
스크롤 등장 연출, 호버 전환, 모달·메뉴 등장 애니메이션은 없다. 전부 즉시 바뀐다.

컨테이너 쿼리 두 곳:
- 강습 카드 — 목록(넓은 칸)에서는 한 줄 5칸, 상세 페이지 옆 칸(좁은 칸)에서는 2줄 카드
- 자유수영 시간표 — 600px 넘으면 레인 × 부 행렬, 좁으면 부별 목록

### impeccable 처리 내역

억제(`.impeccable/config.json` 의 ignore, 인라인 주석) 없이 전부 고쳤다.
루트 설정에 있는 예외는 W39-pour 전용이라 이 폴더와 무관하고, `--no-config` 로도 0건이다.

- `em-dash-overuse`(advisory) — 처음엔 홈·강습·접수·공지 4곳에서 떴다(최대 23개).
  - 빈 값 자리표시 `—`(레인·선택한 반 표), 옵션 `— 마감`, 스크린리더 문구의 `—` 를 지우거나 `·` `,` 로 바꿨다
  - **공지 제목 8개도 바꿨다.** 기획서 카피 예시가 `10월 정기 휴관 — 10월 13일(월)` 꼴이라 처음엔 그대로 따랐다.
    줄표는 부연에 쓰는 정당한 한국어 문장 부호지만, 목록 한 화면에 8개가 반복되면 기계 말투가 된다.
    → `10월 정기 휴관 · 10월 12일(월)`. 사이트 전체의 라벨 구분자(`·`)와도 맞다
- 실패 규칙(anti-pattern)은 처음부터 0건이었다. 기획서 값(서체·색) 중 걸린 것 없음 — 바꾼 토큰 없음

## 한국어

- 라벨·메뉴·제목·표는 명사형. 문장은 안내문·오류 5곳뿐이고 전부 해요체(`확인해 주세요` `없어요`)
- KOREAN §3 표는 안내문·오류에 합쇼체를 적지만, 이번 기획서와 `voice.md` 가 해요체 하나로 정했다. 기획서를 따랐다
- 꾸밈어 대신 수치 — `쾌적한 수온` 이 아니라 `수온 28도`
- 범위는 물결표를 붙여 쓴다(`9월 29일~10월 5일`)
- 검사기를 통과한 뒤 전 문자열을 사람이 한 번 읽었다. 그때 고친 것:
  - 공지 "접수 방법 — **1층** 안내 데스크" → 도면상 데스크가 지하 1층이라 모순. `안내 데스크 방문`
  - `~` 앞뒤 띄어쓰기가 섞여 있던 것 통일
  - `결제 — 3일 안` → `3일 이내`, `보관 수강 종료 후 1년` → `보관 기간 수강 종료 후 1년`
  - 공지 상세 `<title>` 이 `제목 — 날짜 — 새물 수영장` 으로 줄표 둘 → 구분자 `·`
  - 바닥 문구 중간의 마침표 → `·`

## 작업 중 실제로 틀렸던 것

- **공유 브라우저.** Playwright MCP 브라우저를 다른 에이전트가 같이 쓰고 있어 내 탭이 `:4304` 로 넘어갔다.
  이후 검수는 전부 `browser.newContext()` 로 따로 연 창에서 했다
- **블록이 줄눈에서 1px 씩 밀렸다.** `border-top: 1px` 이 높이에 더해져 레인 블록이 385px → 스냅이 408px 로 올리며 빈 줄이 생겼다.
  테두리를 `inset` 그림자로 바꿨다
- **표 행이 48.67px.** 17px 링크와 모노 숫자가 한 줄 안에서 기준선이 달라 줄 상자가 커졌다. 인라인 `span.num`·표 링크에 `line-height: 1`
- **레인 번호가 위로 붙었다.** 위 수정의 `span.num { line-height: 1 }` 이 `.lane-n` 의 48px 줄높이를 이겼다. 모바일 스크린샷에서 발견 → `span.lane-n`
- **View Transitions 가 새 문서에서 안 붙었다.** 옛 문서 `pageswap` 은 전환을 시작했는데 새 문서가 `opt-in disabled` 로 중단.
  `@view-transition` 이 외부 CSS(`site.css`)에만 있었다 → `<head>` 에 인라인 `<style>` 로 먼저 선언, `<link rel="expect" href="#main" blocking="render">` 추가 후 `level-title` 그룹 확인
- **자유수영 행렬이 `자유` 글자 100여 개로 시끄러웠다.** 자유 칸은 비우고(스크린리더에는 `자유`) 강습 칸만 줄눈색으로 채웠다. 표 위에 `빈 칸 자유수영`

## 기술

네이티브 CSS + 바닐라 JS. 프레임워크 없음. 외부 의존은 서체 CSS 둘(jsDelivr Wanted Sans, Google Fonts IBM Plex Mono)뿐.
모달은 `<dialog>`. CSS `round()`·컨테이너 쿼리·문서 간 View Transitions 를 써서 **Chrome 기준**으로 검수했다.

## 남은 것

- `file://` 에서는 문서 간 View Transitions 가 붙지 않는다(출처가 불투명해 같은 출처 조건을 못 맞춘다). 이동은 정상
- `round()` 를 모르는 브라우저는 `.wrap` 폭이 `100% - 32px` 로 떨어져 줄눈과 좌우 끝이 어긋난다. 동작에는 영향 없음
- Firefox·Safari 는 열어 보지 않았다. Chrome 에서만 검수
- 공휴일(한글날·개천절 등) 운영 시각은 규칙을 두지 않았다. 설·추석·1월 1일만 휴관
- 접수는 막아 두었다. 실제 전송 없음
