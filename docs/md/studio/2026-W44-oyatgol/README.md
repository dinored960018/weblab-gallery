## 기능 (실제 동작)

- **오늘 현황 새로 고침** — 정해 둔 5분 간격 값 5묶음을 차례로(10:00 → 10:05 …). 바뀐 숫자만 교체 모션, 화면 읽기 프로그램용 요약 `aria-live`
- **진료 과목 목록** — 줄 단추 `aria-expanded`, 펼침 · 접힘, 주소 해시로 펼침
- **종 탭** — 진료비 · 접종 계산. `aria-selected`, ←/→/Home/End, 포커스 이동
- **진료비 체중 구간** — 숫자 검증(0.1~99.9), 구간 열 강조, 안내 문구 `aria-live`
- **접종 일정 계산** — 태어난 날 필수, 맞은 횟수가 있으면 마지막 날짜 필수, 태어난 날보다 앞선 날짜 오류(`aria-invalid` + 첫 오류 칸 포커스). 기초 접종은 `생후 첫 주 + 회차 × 간격`과 `마지막 + 간격` 중 늦은 날, 기초가 끝나면 마지막 + 1년. 지남 = 오늘 뒤, 2주 안 = 14일 이하. `?s=&b=&v=id.횟수.날짜` 주소 복원 · sessionStorage
- **예약** — 지난 칸(10:00까지) · 찬 칸(날짜 · 칸 해시 시드) · 수술 시간 · 쉬는 날 비활성, 휴진일은 칸 없음. 칸 `aria-pressed` + 읽을 이름("10월 30일 (금) 11:00 한서윤 · 비어 있음"). 폼 검증(보호자 이름 · 휴대전화 형식 · 반려동물 이름 · 체중 · 나이 범위)과 오류 요약(건수 + 링크 → 그 칸 포커스). 접수하면 그 칸이 「내 예약」
- FAQ 아코디언(`aria-expanded`) · 모바일 메뉴(1100 px 아래, 첫 링크 포커스 · Esc · 포커스 복귀 · 배경 스크롤 잠금) · 건너뛰기 링크 · `href="#"` 없음

## AX/DX 기능 10 — 접수 도우미

외부 API 없음. `assets/assist.js` 의 낱말 규칙과 `assets/core.js` 의 계산(이 사이트의 시간표 · 진료비표 · 접종 주기표)으로만 답한다. 판 머리에 **"규칙 기반 안내입니다. … 증상 판단과 약은 수의사가 정합니다."** 저장은 sessionStorage 뿐, 전송 없음.

선 긋기: **응급 신호 낱말**(숨 · 경련 · 삼킴 · 소변을 못 봄 등, `data.mjs` `EMERGENCY.words`)이 있으면 어떤 질문이든 먼저 붉은 「예약보다 전화가 먼저입니다」 카드(전화 두 개 + 읽은 신호 링크)를 내고 예약 칸을 찾지 않는다. **진단 · 처방 · 약 용량**(용량 · 먹여도 · 처방 · 진단 · 무슨 병 · 진통제 …)은 답하지 않고 상담 요청서로 넘긴다.

- 접종 계산은 "기초 횟수 + 간격 + 해마다 추가" 한 규칙이다. 항체가 검사 결과 · 백신 제품별 간격 · 나이 많은 동물의 첫 접종(기초 횟수 축소)은 반영하지 않았다. 화면에 "실제 순서는 진료 때 수의사가 정합니다"를 밝혔다
- 응급 낱말은 목록 대조라 "떨어졌어요"처럼 뜻이 여럿인 말은 일부러 뺐고("높은 데서 떨어" · "에서 떨어졌"만), 목록에 없는 표현의 응급은 못 잡는다. 응급 페이지와 첫 화면 띠가 늘 보이게 한 이유다
- 도우미는 낱말 규칙이라 표에 없는 질문은 "답할 수 없습니다" + 상담 요청서로 보낸다. 반려동물 정보가 들어간 문장은 질문보다 칸 채우기로 먼저 읽는다
- 예약 · 상담 요청 · 기록 · 대화는 sessionStorage 에만. 탭을 닫으면 사라진다. file:// 에서 페이지 사이 sessionStorage 는 Chromium 에서 이어짐을 확인, 다른 브라우저는 확인하지 않음
- 공휴일은 반영하지 않았다(일요일 · 11월 7일 원내 교육만 휴진). 예약은 30분 한 칸
- 모션 녹화(`record-motion.mjs`)는 하지 않았다 — 두 모션의 지속시간 · 이징은 computed style 과 Playwright 로 확인
- Safari · Firefox 에서 직접 열어 보지 않았다. 날짜 입력은 브라우저 기본 달력(헤드리스 Chromium 은 영어 자리 표시 `mm/dd/yyyy`)
