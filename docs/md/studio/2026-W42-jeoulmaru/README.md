## 기능 (실제 동작)

- **검정 주기 계산** — 종류 select(분동 포함) + 마지막 검정일(연-월-일) → 만료일 · 남은 일수 · 유예 끝. 빈 값 · 형식 오류 · 없는 날짜 · 미래 날짜 · 2015년 이전은 필드 아래 문장 + `aria-invalid`. 만료면 "만료 N일 경과"(유예 중 / 유예 지남 구분) + 예약 링크. 만료 60일 안이면 예약 안내. `?type=&last=` 기록 · 복원
- **허용오차 판정** — 최대 용량 · e · 측정 점(추가 · 지우기, 1~5줄). 눈금 수 100~10,000 검사, 음수 · 0 · 용량 초과 오류. 점마다 하중 구간(0~500 e / ~2,000 e / 초과) → 허용 ± 1 · 2 · 3 e, 편차 · 점 판정, 전체 판정 한 줄. 불합격은 색이 아니라 "불합격" 낱말 + 밑줄 + 굵기. `?cap=&e=&pts=500:500,2000:2002` 기록 · 복원
- **수수료 계산** — 입력할 때마다 셈. 종류 × 용량 구간 단가, 분동은 개수 단가(구간 끔), 계근대는 300 kg 초과 · 출장 강제. 6대 이상 단체 감면 10 %(출장비 제외), 출장비 = 기본 30,000원 + 편도 km(올림) × 1,000원. 계산 근거 줄 나열 + 합계, `견적 인쇄`(인쇄 스타일은 견적만), `?type=&band=&n=&trip=&km=` 복원
- **방문 예약** — 10~11월 달력(주말 · 한글날 · 지난 날 · 마감 비활성, 잔여는 날짜 시드로 고정), 시간대 5(마감 비활성), 대상 1~4건(종류 · 대수 1~20), 이름 · 휴대전화(숫자 · 하이픈, 010 형식) · 출장이면 장소 · 동의. `다음` 단추가 단계별 검사 후 다음 단계로 이동 · 포커스. 접수 시 오류 요약(포커스 이동 · 링크로 칸 이동), 출장은 저울 3대부터(계근대 1대 가능). 완료 시 `JM-261014-041`부터 번호 발급, sessionStorage 보관, 결과 패널로 포커스, 조회 링크
- **접수 조회** — 형식 검사(소문자 허용 → 대문자로), 이 탭에서 예약한 번호는 "접수 · 방문 예정"과 예약 내용, 그 밖은 번호 시드로 존재 여부와 단계(접수일부터 지난 평일 수) 결정. 없는 번호 · 90일 지난 번호는 빈 결과 문장. `?no=` 기록 · 복원. 예시 번호 4개(단계 0~3이 다 나오게 골랐다)
- **분동 등급 탭** — `role="tablist"`, `aria-selected`, ←/→/Home/End, roving tabindex, 단면 SVG(`<template>`)와 정보 · 허용 편차 표 갱신, `?grade=` 복원
- **자주 묻는 것** — `details` 12, 펼친 항목을 `?open=` 으로 기록 · 복원
- **공통** — 건너뛰기 링크, 모바일 메뉴(1240 px 아래, 첫 링크 포커스 · Esc 닫기 · 포커스 복귀 · 배경 스크롤 잠금), 결과 `aria-live`, `href="#"` 없음(눈금자 목차는 같은 쪽 구획 `#id`), 개인정보는 서버로 가지 않음을 폼 옆에 표시

- 눈금자 숫자(0 · 250 · 500 …)와 구획 목차의 값 표시가 같은 높이에서 겹침 → 눈금 숫자를 빼고 목차 값만 남김
- impeccable 파일 검사 `low-contrast` 5건 — `@media print` 의 `.panel { background: #fff }` 를 정적 분석이 화면 규칙으로 읽어 패널 보조 글자를 흰 바탕 위로 계산 → 인쇄에서도 패널 색을 유지(`print-color-adjust: exact`)하고 흰 바탕 규칙 삭제
- 예시 접수번호 3개가 시드 규칙(`hash % 4 === 0` 은 없는 번호)에 걸려 "조회 결과 없음"이 나옴 → 단계 0~3이 다 나오는 번호로 교체
- 분동 단면 설명 글자가 도형 위에 겹침 → 그림 아래로
- 약도 '반입구' 글자가 도로 위에 겹침 → 도로 왼쪽으로
- 전체 페이지 스크린샷에서 `loading="lazy"` 사진이 빈 칸으로 찍힘 — 화면 결함이 아니라 캡처 문제(브라우저 `naturalWidth` 정상, 화면 단위 캡처 `refs/state-visit-photos.jpg` 확인)
