# 여늘시립천문대 — 창작 (모작 아님)

가상의 도시 여늘시의 시립 천문대 사이트. 한국어. 2026-10-05.
기획: [`research/2026-W41/build-concepts.md` §1](../../research/2026-W41/build-concepts.md) (사용자 승인: 시립 천문대 컨셉 "추천대로 바로")

## 한 줄

오늘 밤(2026-10-05) 관측이 되는지 — 구름·달·하늘 밝기로 낸 시간대별 관측 지수 — 와 그 시각 지평선 위 천체를 먼저 보여 주고, 관측 프로그램 회차를 예약하게 하는 시립 천문대.
화면 문법은 원형 계기판이다. 계산한 성도 원판과 둘레 방위 눈금이 화면 중심이고, 18~05시 시간 축 띠가 페이지를 가로지르며, 천체는 연감(ephemeris) 표로 읽는다.

## 이름·소재

- **여늘시립천문대**(가상). 가상 도시 여늘시, 여늘산 서쪽 능선 해발 612 m. 로마자 `yeoneul`
- 이름 확인(2026-10-05 웹 검색): `"여늘" 천문대 OR "여늘시" OR "여늘산"`, `"여늘"` → 같은 이름의 도시·산·천문대·상호 없음. '가늠재'는 일반어라 버림
- 실존 천문대·지자체·한국천문연구원 이름과 로고를 쓰지 않았다. 발(footer)·예약·지수 계산식에 "가상의 천문대, 기상값·광공해 값·잔여석·버스 시간표는 지어낸 것, 예약은 전송하지 않음"을 밝힘
- 메일 `sky@yeoneul.example`. 전화번호 없음

## 관측 지수 (기상은 가상값)

`지수 = 0.40 × 구름 + 0.15 × 달 + 0.15 × 투명도 + 0.15 × 시상 + 0.15 × 하늘 밝기`, 각 항 0~100. 해 고도 −6°~−18°는 박명 계수 0.3~1을 곱하고, 구름 80% 이상이면 20 상한. 달 항 = 100 − 160 × 조명률 × sin(달 고도).
결과: 18시 23(D) · 19시 54(C) · 20시 85 · **21시 91(A, 최고)** · 22시 86 · 23시 71(B, 구름 35%) · 0시 67(B) · 1시 80 · 2시 86 · 3시 85 · 4시 76 · 5시 71. 홈의 계산식 펼침에 입력값 표 전부 공개.
