## 기능 (실제 동작)

- **에이전트 패널** — 모든 페이지. 머리의 `에이전트` 단추(`aria-expanded`)와 패널 `닫기`로 열고 닫음, Esc(패널 안 포커스 · 좁은 화면 시트)로 닫고 포커스를 머리 단추로 돌려줌, 열면 입력 칸으로 포커스. 넓은 화면은 접은 상태를 탭 안에서 기억. 좁은 화면(1199 px 이하)은 아래 시트 + 배경 스크롤 잠금. 대화 기록 · 장바구니는 sessionStorage(이 탭)라 페이지를 옮겨도 이어짐
- **에이전트 규칙**(`assets/core.js` `reply`) — 사이트 데이터로만 답함. 장바구니 → 인원 + 용도(숫자 · "두 명" 같은 한글 수, 부위를 같이 말하면 그 부위로 · 재고 부족이면 대체 부위나 남은 양까지만 담음 · 30인 초과는 전화 안내) → 부위 이름(소/돼지 등심처럼 겹치면 둘 다, "돼지"를 붙이면 하나) → 매장 · 동네 → 숙성 → 픽업 → 영업 → 식당 → 가격 → 인사 → "이 질문에 맞는 규칙이 없습니다." 답마다 "규칙: ○○" 표시. 조사(을/를 · 은/는 · 으로/로)는 받침으로 고름
- **체크 조회** — 0개면 오류 + 첫 체크로 포커스. 단계 3개가 차례로 진행 중 → 완료, 휴무 매장(강변점)을 고르면 픽업을 다른 매장으로 옮기고 그 사실을 단계에 적음. 결과는 장바구니 초안에 담기고 픽업 매장 · 시각은 주문 페이지에 미리 골라짐
- **부위표** — 탭(`aria-selected`, ←/→/Home/End), 도해 부위(`role=button` · `aria-pressed`, 클릭 · Enter · Space) ↔ 표 줄 단추 연동, 고른 부위 정보 + 에이전트에게 묻기. 용도 고르기(맞지 않는 부위는 도해에서 흐려짐, 0종이면 빈 문장), 정렬 3종, 개수 `aria-live`
- **주문 계산** — 부위를 바꾸면 용도 목록과 권장 두께가 따라감. 인원 1~30 정수 검증(`aria-invalid` · 담기 비활성), 재고 부족이면 담기 비활성. 장수 = 중량 ÷ (1 cm 한 장 무게 × 두께)
- **픽업 예약** — 휴무 매장 비활성, 지난 · 마감 슬롯 비활성, 오류 요약(건수 + 칸 링크, 요약으로 포커스, 링크 → 칸 포커스), 휴대전화 형식, 완료 시 픽업 번호 `SG-1021-101`부터 · 완료 영역으로 포커스. 전송 없음
- **매장 고르기** · **식당 예약**(매장 휴무 요일 비활성 · 오늘 마감 시각 · 어른 1명 이상 · 20명 이하 · 상차림비 합계 실시간) · **매장 열기 문의**(3단계, 판정 · 준비 필요 항목, 문의 6칸 검증) · **소식 분류**(`aria-pressed`) · **FAQ**(`aria-expanded`) · **모바일 메뉴**(899 px 이하, 첫 링크 포커스 · Esc · 포커스 복귀 · 배경 스크롤 잠금) · 건너뛰기 링크 · `href="#"` 없음

## 레이아웃

본문(왼쪽, 최대 1240 px, 카드 없는 연속 흐름 · 괘선 구분) + 에이전트 레일(오른쪽 고정 400 px). 레이아웃 판단은 뷰포트가 아니라 `main` 의 컨테이너 쿼리로 해서 레일을 접으면 본문이 넓어진 만큼 다단이 된다.
부위표의 "도해 왼쪽 · 표 오른쪽"은 본문 폭 1040 px 이상(레일을 접은 1440 px, 또는 레일을 편 1680 px 이상)에서 나란히, 그보다 좁으면 도해 위 · 표 아래로 쌓는다 — 레일을 편 1440 px 에서 나란히 두면 표 6열이 줄바꿈으로 깨졌다. 560 px 이하 본문에서 부위표는 줄마다 `항목 값` 격자로 바뀐다.

## 모션 — 둘

| 모션 | 내용 |
|---|---|
| 에이전트 단계 진행 | 단계마다 대기(빈 칸) → 진행 중(분홍, 칸 절반 채움) → 완료(녹색) 400 ms 간격. 홈 본문 단계 표시와 레일 기록이 같이 진행. 끝나면 응답 줄이 90 ms 간격으로 하나씩 `opacity 0 → 1` · `translateY(6px) → 0` 400 ms `cubic-bezier(0.22, 1, 0.36, 1)`. 상태 칩 대기 → 작업 중 → 완료 |
| 부위 하이라이트 | 도해 부위를 고르면 면이 분홍으로 220 ms 채워지고(같은 이징) 표의 그 줄이 한 단 밝아지며 화면 안으로 부드럽게 스크롤(`block: nearest`) |

보조: 모바일 시트 올라옴 300 ms, FAQ 더하기표 회전 200 ms. 깜박이는 진행 표시는 impeccable `blinking-cursor` 에 걸려 정지 상태(칸 절반 채움)로 바꿨다.
`prefers-reduced-motion: reduce` — 모든 animation · transition 끔, 단계는 기다림 없이 즉시 완료, 스크롤은 즉시(Playwright `reducedMotion: 'reduce'` 로 확인: 80 ms 안에 3단계 완료, 기록 줄 `animation-name: none`).
